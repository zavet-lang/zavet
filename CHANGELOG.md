# Changelog

## 1.1.0

### Новые возможности
- **Опциональные аннотации типов**: `пусть x: целое = 42`, `измени s: строка? = ничего`, `слово f(a: число) -> целое`, поддержка пользовательских `образ`ов и наследования; сохраняются в `zavet формат` и `zavet док`
- **Отладчик**: `zavet отладка файл.молитва` — пошаговое исполнение (`шаг`/`далее`/`выйти`/`продолжить`), точки останова, просмотр переменных, вычисление выражений, стек вызовов
- **Генератор API-документации**: `zavet док путь [-o файл.md] [--только-экспорт]`
- **Байткод-VM (`--vm`)**: поддержка слов (функций) и рекурсии, циклов `для i от a до b`, `прерви`/`продолжи`, массивов и индексации, `длина`, логики `и`/`или`/`не`, `//`, составных присваиваний `+= -= *= /=`, быстрые пути для `int64`
- **Стандартная библиотека**:
  - `веб` — веб-фреймворк (маршруты `:id`/`*path`, группы, middleware `веб.cors`/`веб.логгер`, ответы `текст`/`html`/`json`/`редирект`/`ошибка`/`кука`, `при_ошибке`, тестирование `обработать` без сети)
  - `почта` — SMTP (STARTTLS/TLS), сборка RFC 5322 MIME, проверка email
  - `yaml` — чистый Go-парсер и сериализатор YAML
  - `сжатие` — `gzip`, `zlib` и `zip` (с защитой от Zip Slip)
  - `питон` и `js` — вызов Python 3 и Node.js с передачей данных через JSON
- **Реестр и установка**: встроенный каталог из 15 пакетов + `zavet реестр [запрос]`; конфиги для Homebrew (`packaging/homebrew/zavet.rb`), Scoop (`packaging/scoop/zavet.json`), APT `.deb` (`packaging/apt/build-deb.sh`) и `.goreleaser.yml` (`nfpms`, `brews`, `scoops`)

### Сообщения об ошибках
- Все тексты ошибок (интерпретатор, парсер, стдлиб, линтер, `zavet` CLI, менеджер пакетов) переписаны в библейском стиле: «сын мой, …», «аще», «вникни», «призови»
- Подсказка `💡 Подсказка:` заменена на `📖 Наставление:`; код, имена и подстановки в сообщениях не меняются

### Язык
- Деструктуризация с `измени`: `измени a, b = …`, `измени [a, b] = …` создаёт **изменяемые** связи (раньше — неизменяемые)
- Наследование: цепочка любой глубины; `родитель.метод(…)` работает в любом методе (не только в конструкторе); `новый Класс(…)` учитывает наследование; конструктор ближайшего предка используется, если у образа нет своего `создать`
- Escape-последовательность `\b` (Backspace) в строках (нужна для `окно.символ()`)
- `продолжи` больше не «протекает» из вызываемых слов во внешний цикл

### Исправления
- `%` на нуле у целых и `//` у дробных больше не роняют интерпретатор паникой: ошибка «деление на ноль»; `7.0 // 0.5` теперь `14`
- `--vm`: деление и остаток на ноль — ошибка, а не паника / бесконечность

### Безопасный режим (`--безопасный`)
- Закрыты пробелы: `файлы.добавить/переименовать/создать_дир/удалить_дир`, `ос.сменить_директорию/установить_переменную/переменная`, `бд.подключить`, `http.сервер`, `вс.сервер` — запрещены; `файлы.список/размер/существует/это_файл/это_дир`, `существует_файл`, `шаблон.файл`, `бд.открыть` (кроме `:memory:`) и `приими` ограничены песочницей; `вс.подключить` проверяется списком `--разрешить-хост`

### Окно и примеры
- `окно.иконка`, `окно.список_иконок`: глифы Font Awesome 6 Solid
- Модульный браузер на Завете: [`examples/браузер/`](examples/браузер) (url, сеть, html, вёрстка, сессия, хром, приложение)

### Документация
- Полная документация на русском: [docs/ДОКУМЕНТАЦИЯ.md](docs/ДОКУМЕНТАЦИЯ.md) (главы 01–07, стандартная библиотека, окно)
- Переписаны [СТИЛЬ.md](СТИЛЬ.md), [PRINCIPLES.md](PRINCIPLES.md) и [docs/СИНТАКСИС.md](docs/СИНТАКСИС.md) под текущий язык

## 1.0.0

### Язык
- Bound methods: `объект.метод` сохраняет `это`
- `пусть` / `измени`: локальный `измени` не блокируется внешним `пусть`
- Модуль `окно`: Win32 на Windows; HTML5 canvas в браузере на Linux/macOS
- `окно`: мышь (`мышь_x`/`мышь_y`/`мышь`/`клик`), `колесо`, `символ` (ввод текста)
- Пример [`examples/22_браузер.молитва`](examples/22_браузер.молитва) — GUI-браузер с вкладками, историей и HTML-рендером

### CLI
- `main.Version` / `zavet версия` (1.0.0)
- `--безопасный`: песочница cwd, без процессов/записи/серверов
- `--разрешить-хост=`: исходящий HTTP allowlist
- `--vm`: байткод для арифметики / `возгласи` / `если` / `доколе`

### Инфраструктура
- Go-модуль `zavet`
- CI Ubuntu+Windows, goreleaser, MIT, docs/СТДЛИБ.md

### Известные ограничения
- `--vm` — подмножество; полный язык через tree-walker
- `окно.текст` в браузерном backend пока заглушка
