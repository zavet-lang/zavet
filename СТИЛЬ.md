# Стиль кода Завета

Этот документ описывает единый стиль записи кода на Завете. Стиль — не вопрос вкуса, а **общий канон**, чтобы любой код читался одинаково. Команда `zavet формат` приводит файлы к этому стилю автоматически (см. [docs/06_ИНСТРУМЕНТЫ.md](docs/06_ИНСТРУМЕНТЫ.md#форматтер-формат)).

Главный принцип: **меньше когнитивной нагрузки на читателя**. Если правило снижает нагрузку — оно есть. Если не снижает — его нет.

## Отступы

- Один уровень = **4 пробела**, никогда не табуляция.
- Закрывающее `конец` стоит на том же уровне, что и открывающее слово (`слово`, `образ`, `если`, `для`, `доколе`, `попытка`, `разбери`, `тест`, `род`).

```
слово плюс(a, b)
    аминь a + b
конец
```

## Пробелы

| Где | Пример |
|-----|--------|
| один пробел вокруг бинарных операторов | `a + b`, `x == y`, `n % 2` |
| без пробела у унарных | `-x`, `не x`, `...args` |
| один пробел после запятой | `[1, 2, 3]`, `f(a, b)` |
| один пробел после двоеточия | `если x: y`, `когда 1: "Пн"`, `{"a": 1}` |
| один пробел после ключевых слов | `если x`, `для i от 1 до 10` |
| без пробелов внутри скобок | `f(2, 3)`, `[1, 2]`, `{"a": 1}` |
| без пробелов вокруг точки | `это.имя`, `мат.пи` |
| один пробел вокруг `=` | `пусть x = 10` |
| один пробел в стрелке | `x => x * 2` |
| один пробел вокруг `\|>` | `данные \|> фильтр(…)` |

## Переменные

- `пусть` — по умолчанию (неизменяемая связь).
- `измени` — только когда значение действительно меняется.

```
пусть имя = "Аня"
пусть возраст = 25
измени счётчик = 0
```

Накопители в циклах и счётчики — `измени`; всё остальное — `пусть`. Линтер (`zavet проверить`) предупредит о неиспользуемых переменных и о присваивании `пусть`-связи.

## Имена

| Что | Стиль | Пример |
|-----|-------|--------|
| переменные, слова | `строчные_через_подчёркивание` | `сумма_цифр`, `найти_первое` |
| образы, роды | `КамелКейс` (каждое слово с заглавной) | `Точка`, `СписокЗадач` |
| константы | строчные, как переменные | `пи`, `золотое_сечение` |
| предикаты (возвращают `истина`/`ложь`) | оканчиваются на `?` | `простое?`, `пустой?` |
| внутренние имена | начинаются с `_` | `_вспомогательное` |

Константы не пишем заглавными (`ПИ`) — это «крик», шумит при чтении.

Не называйте переменные ключевыми словами (`в`, `и`, `или`, `не`, `от`, `до`, `по`, `из`, `как`, `это`, …) — список в [docs/02_ЯЗЫК.md](docs/02_ЯЗЫК.md#лексика).

## Кавычки

- Для строк — двойные `"…"`: они поддерживают интерполяцию `{…}`.
- Одинарные `'…'` — только когда в тексте много фигурных скобок или двойных кавычек (JSON, CSS, шаблоны): интерполяции в них нет.
- Многострочный текст — `"""…"""`.

```
пусть приветствие = "Привет, {имя}!"
пусть json_текст = '{"имя": "Аня", "теги": []}'
```

## Комментарии

- Только `#`. Никаких `//` (это целочисленное деление) и `/* */`.
- На отдельной строке **перед** кодом, который описывают. Концевые комментарии форматтер переносит на строку выше.
- Обычное предложение с заглавной буквы и точкой в конце; после `#` один пробел.

```
# Считает n-е число Фибоначчи рекурсивно.
слово фиб(n)
    если n < 2: аминь n
    аминь фиб(n - 1) + фиб(n - 2)
конец
```

## Управление потоком

### Условия

```
если возраст >= 18
    возгласи("Взрослый")
иначеесли возраст >= 14
    возгласи("Подросток")
иначе
    возгласи("Ребёнок")
конец
```

`иначеесли` — **одно слово**. Для одного короткого выражения допустима форма через двоеточие:

```
если n <= 1: аминь 1
если n < 0: бросить "отрицательное число"
пусть знак = если x >= 0: "плюс" иначе: "минус"
```

### Циклы

```
для i от 1 до 10            # 1 … 10
    тело
конец

для i от 0 до 10 по 2       # шаг 2
    тело
конец

для x в массив
    тело
конец

для индекс, x в массив      # индекс и значение
    тело
конец

доколе условие
    тело
конец
```

### Сопоставление

```
пусть день = разбери номер
    когда 1: "Пн"
    когда 2: "Вт"
    иначе: "?"
конец
```

Каждое `когда` — с отступом 4 от `разбери`.

## Слова (функции)

### Блочная форма

```
слово факториал(n)
    если n <= 1: аминь 1
    аминь n * факториал(n - 1)
конец
```

### Однострочная форма

```
слово квадрат(x): x * x
слово чётное?(n): n % 2 == 0
```

Только когда тело — одно короткое выражение.

### Параметры

```
слово степень_по_умолчанию(основание, показатель = 2): степень(основание, показатель)
слово максимум(...числа): макс(числа)
```

Лямбды: `x => x * 2` (один параметр без скобок), `(a, b) => a + b`.

Явно пишите `аминь` в длинных телах: неявный результат (значение последнего выражения) допустим только в коротких словах и лямбдах.

## Образы

```
образ Точка
    слово создать(x, y)
        это.x = x
        это.y = y
    конец

    слово длина()
        аминь корень(это.x * это.x + это.y * это.y)
    конец
конец
```

- Между методами — **1 пустая строка**.
- Конструктор — `создать`, всегда первым методом.
- Поля — через `это.имя`.
- Метод предка — `родитель.метод()`.

```
образ Кот наследует Животное
    слово голос()
        аминь "{это.имя}: мяу"
    конец
конец
```

## Литералы

Короткие коллекции — в одну строку:

```
пусть числа = [1, 2, 3, 4, 5]
пусть человек = {"имя": "Иван", "возраст": 30}
```

Длинные и со структурами — многострочно, **с завершающей запятой** (форматтер добавляет её сам: diff в git при добавлении элемента минимален):

```
пусть команда = [
    {"имя": "Аня", "возраст": 22},
    {"имя": "Боря", "возраст": 25},
]
```

## Модули

В начале файла, одним блоком; после блока — одна пустая строка. Порядок импортов — авторский, форматтер его не меняет.

```
приими матем из "матем"
приими утилиты из "./утилиты.молитва" как у

возгласи(матем.факториал(5))
```

Экспорт — `открой` перед определением:

```
открой пусть пи = 3.141592653589793

открой слово квадрат(x): x * x
```

Стандартные модули (`json`, `файлы`, `время`, …) импортировать не обязательно.

## Декораторы

На отдельной строке прямо перед определением слова:

```
@логировать
слово квадрат(x): x * x

@логировать
@кешировать
слово дорогое(n)
    аминь n
конец
```

## Конвейер

Длинный конвейер `|>` — с продолжением на новых строках и отступом 4:

```
пусть результат = числа
    |> фильтр(x => x % 2 == 0)
    |> преобразовать(x => x * x)
```

Короткий — в одну строку: `пусть квадраты = числа |> преобразовать(x => x * x)`.

## Тесты

```
тест "сложение"
    проверить сложить(2, 3) == 5
конец
```

Название теста — короткая фраза, описывающая поведение; одна идея — один `тест`.

## Пустые строки

- **Одна** пустая строка между определениями верхнего уровня (слова, образы).
- **Одна** между методами образа.
- **Одна** между блоком импортов и кодом.
- **Ноль** перед `конец`, `иначе`, `иначеесли`.
- **Ноль** в начале и в конце файла.
- Лишние (две и более) схлопываются в одну.

## Длина строк

Рекомендуемая длина — до 100 символов. Форматтер строки не переносит: это ломает намеренное оформление.

## Точки с запятой

Не используются. Перенос строки — конец инструкции.

## Запрещённые (удалённые) формы

Устарели и в новом коде не встречаются: `конст`, `функция`, `процедура`, `вернуть`, `да`/`нет`, `вывод(…)`, `// комментарий`. Соответствия — в [docs/07_ОСОБЕННОСТИ.md](docs/07_ОСОБЕННОСТИ.md#устаревшие-слова).

## Что делает форматтер

1. Приводит отступы к 4 пробелам.
2. Расставляет пробелы вокруг операторов и после знаков пунктуации.
3. Схлопывает множественные пустые строки.
4. Ставит завершающую запятую в многострочных литералах.
5. Убирает пробелы в конце строк и гарантирует перевод строки в конце файла.
6. Переносит концевые комментарии на строку выше.

Форматтер **не** сортирует импорты, не переносит длинные строки, не переименовывает идентификаторы, не превращает блочные формы в однострочные и наоборот — это выбор автора. Результат идемпотентен.

## Образец

```
# Считает количество простых чисел до n.
слово простых_до(n)
    измени счёт = 0
    для i от 2 до n
        если простое?(i)
            счёт += 1
        конец
    конец
    аминь счёт
конец

образ Очередь
    слово создать()
        это.элементы = []
    конец

    слово добавить_в_конец(x)
        добавить(это.элементы, x)
    конец

    слово взять()
        если длина(это.элементы) == 0: аминь ничего
        пусть первый = это.элементы[0]
        это.элементы = это.элементы[1:]
        аминь первый
    конец
конец
```
