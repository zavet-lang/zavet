# Браузер Завета — модульная схема

Ориентир: [Ladybird](https://github.com/LadybirdBrowser/ladybird)
(`Documentation/ProcessArchitecture.md`, `LibWebFromLoadingToPainting.md`).

Полноценный Chromium (~десятки ГБ) сюда не клонируется — берём **архитектуру**
настоящего браузера и реализуем её на Завете.

| Ladybird | Модуль Завета | Роль |
|----------|---------------|------|
| UI | `хром.молитва` | вкладки, тулбар, омнибокс, закладки |
| Hub | `сессия.молитва` | вкладки, история, адрес, фокус |
| RequestServer / LibHTTP | `сеть.молитва` | асинхронный HTTP, about: |
| LibURL | `url.молитва` | резолв ссылок |
| LibWeb (parse) | `html.молитва` | HTML → блоки |
| LibWeb (layout/paint) | `вёрстка.молитва` | блоки → элементы + hit-test ссылок |
| Compositor | `приложение.молитва` | кадр: очистка → хром → контент → статус |
| — | `страницы.молитва` | about:home / example / ошибка |
| — | `строки.молитва` | вырезка, сущности, перенос |

Вход: [`../22_браузер.молитва`](../22_браузер.молитва) — процесс UI, вызывает `приложение.запустить()`.

Ограничения (как и раньше): без JS/CSS-движка и декодера картинок.
