# Стандартная библиотека

Стандартные модули — это словари со встроенными словами. Они доступны **по имени без импорта** (`json.разобрать(…)`); `приими json из "json"` допустимо, но не обязательно (см. [главу 04](04_ОШИБКИ_ТЕСТЫ_МОДУЛИ.md#модули)). Собственная переменная с тем же именем перекрывает модуль.

Базовые встроенные слова (`длина`, `фильтр`, `читать_файл` и др.) описаны в [главе 05](05_ВСТРОЕННЫЕ.md). Здесь — модули.

| Модуль | Назначение |
|--------|------------|
| [`мат`](#мат) | константы и функции |
| [`время`](#время) | время, пауза, форматирование |
| [`json`](#json) | разбор и сериализация |
| [`регвыр`](#регвыр) | регулярные выражения |
| [`файлы`](#файлы) | файловая система |
| [`путь`](#путь) | работа с путями |
| [`ос`](#ос) | окружение, процессы |
| [`крипто`](#крипто) | хеши, HMAC, AES, JWT, кодировки |
| [`случайное`](#случайное) | случайные числа |
| [`http`](#http) | клиент и сервер |
| [`csv`](#csv) | CSV |
| [`cli`](#cli) | аргументы командной строки |
| [`шаблон`](#шаблон) | текстовые шаблоны |
| [`бд`](#бд) | SQLite и PostgreSQL |
| [`вс`](#вс) | WebSocket |
| [`окно`](#окно) | графическое окно |

Замечания, общие для всех модулей:

- Константы вызываются **без скобок**: `мат.пи`, `ос.имя`; функции — со скобками.
- Ошибки (нет файла, сеть, SQL, неверный тип аргумента) — обычные ошибки выполнения, их ловит `попытка … поймать`.
- Ограничения [безопасного режима](07_ОСОБЕННОСТИ.md#безопасный-режим) относятся к `файлы`, `ос`, `http`.

## мат

| Имя | Описание |
|-----|----------|
| `мат.пи`, `мат.е`, `мат.бесконечность` | константы (`FLOAT`) |
| `мат.sin(x)`, `мат.cos(x)`, `мат.tan(x)` | тригонометрия, радианы |

Корень, степень, модуль, минимум и максимум — встроенные `корень`, `степень`, `абс`, `мин`, `макс`.

```
возгласи(мат.sin(мат.пи / 2))      # 1.0
возгласи(мат.пол(-2.6))            # -3.0
```

## время

Метки времени — целые числа. `сейчас()` — секунды Unix, `метка()` — миллисекунды. Форматы — по образцу Go: `2006-01-02 15:04:05` (год 2006, месяц 01, день 02, час 15, минута 04, секунда 05).

| Слово | Описание |
|-------|----------|
| `время.сейчас()` | секунды с 1970-01-01 |
| `время.метка()` | миллисекунды |
| `время.метка_нс()` | наносекунды |
| `время.год()`, `месяц()`, `день()`, `час()`, `минута()`, `секунда()` | компоненты **текущего** (локального) времени |
| `время.строка([секунды], [формат])` | текст из меток **в секундах**; без аргументов — текущее время; формат по умолчанию `2006-01-02 15:04:05` |
| `время.формат(мс, формат)` | текст из метки в **миллисекундах** |
| `время.разобрать(текст, [формат])` | метка в миллисекундах (UTC); формат должен совпасть с текстом |
| `время.разница(мс1, мс2)` | модуль разности в миллисекундах |
| `время.спать(мс)` | пауза |

```
пусть начало = время.метка()
время.спать(100)
возгласи("прошло {время.разница(начало, время.метка())} мс")
возгласи(время.строка())                       # 2026-11-26 12:00:00
возгласи(время.формат(86400000, "02.01.2006")) # 02.01.1970
```

## json

| Слово | Описание |
|-------|----------|
| `json.разобрать(строка)` | текст → значения: объект → словарь, массив → массив, число → `INTEGER` (если целое) или `FLOAT`, `true/false` → `истина/ложь`, `null` → `ничего`. Неверный JSON — ошибка |
| `json.создать(значение)` | значение → компактный JSON-текст |

```
пусть д = json.разобрать('{"имя": "Аня", "теги": ["a", "b"], "x": null}')
возгласи(д.имя, " ", д.теги[1])          # Аня b
возгласи(json.создать({"a": [1, 2.5, истина, ничего]}))   # {"a":[1,2.5,true,null]}
```

Литерал JSON удобно писать в одинарных кавычках: в `"…"` символы `{ }` запускают интерполяцию. В `json.создать` ключи словаря, не являющиеся строками, пропускаются; значения неподдерживаемых типов (слова, экземпляры) записываются строкой.

## регвыр

Регулярные выражения синтаксиса Go (RE2). Обратные ссылки и lookahead не поддерживаются.

| Слово | Описание |
|-------|----------|
| `регвыр.совпадает(текст, шаблон)` | `истина`/`ложь` |
| `регвыр.найти(текст, шаблон)` | массив **всех** совпадений (строк) |
| `регвыр.заменить(текст, шаблон, замена)` | замена всех совпадений; в замене допустимы `$1`, `${имя}` |

```
регвыр.найти("a1b22c333", "[0-9]+")     # [1, 22, 333]
регвыр.заменить("a1b22", "[0-9]+", "#") # a#b#
```

## файлы

Полный набор файловых операций. Пути — строки; относительные считаются от рабочей папки процесса.

| Слово | Описание |
|-------|----------|
| `файлы.читать(путь)` | содержимое строкой |
| `файлы.записать(путь, текст)` | перезапись (создаёт файл) |
| `файлы.добавить(путь, текст)` | дописывание в конец (создаёт файл) |
| `файлы.существует(путь)` | `истина`/`ложь` |
| `файлы.удалить(путь)` | удалить файл или пустую папку |
| `файлы.переименовать(старый, новый)` | переименование / перемещение |
| `файлы.список(папка)` | массив **имён** (без пути) |
| `файлы.создать_дир(путь)` | создаёт папку со всеми родителями |
| `файлы.удалить_дир(путь)` | удаляет папку **рекурсивно** |
| `файлы.размер(путь)` | размер в байтах |
| `файлы.это_файл(путь)`, `файлы.это_дир(путь)` | `истина`/`ложь` |

```
файлы.записать("журнал.txt", "строка 1\n")
файлы.добавить("журнал.txt", "строка 2\n")
для имя в файлы.список("."): возгласи(имя)
```

## ос

| Имя | Описание |
|-----|----------|
| `ос.имя` | константа: `windows`, `linux`, `darwin` |
| `ос.архитектура` | константа: `amd64`, `arm64`… |
| `ос.разделитель_путей` | константа: `\` или `/` |
| `ос.аргументы()` | **все** аргументы процесса, включая бинарник и имя скрипта; для пользовательских флагов удобнее [`cli`](#cli) |
| `ос.переменная(имя)` | переменная окружения или `ничего` |
| `ос.установить_переменную(имя, значение)` | задать для процесса |
| `ос.текущая_директория()` / `ос.сменить_директорию(путь)` | рабочая папка |
| `ос.домашняя_директория()` / `ос.временная_директория()` | |
| `ос.запустить(команда, арг…)` | запускает программу, возвращает её stdout строкой; ненулевой код возврата — ошибка. Только строковые аргументы, без оболочки (shell) |

```
пусть р = ос.выполнить("git", "status", "--short")

```

Команды оболочки вроде `echo` на Windows запускайте через `ос.запустить("cmd", "/c", "echo", "привет")`.

## крипто

Все слова принимают **строки**; бинарные результаты возвращаются в виде текста (hex или base64).

| Слово | Описание |
|-------|----------|
| `sha256(s)`, `sha1(s)`, `md5(s)` | хеш в hex |
| `hmac_sha256(сообщение, ключ)`, `hmac_sha1(сообщение, ключ)` | HMAC в hex |
| `base64_кодировать(s)` / `base64_декодировать(s)` | Base64 (стандартный алфавит) |
| `hex_кодировать(s)` / `hex_декодировать(s)` | hex |
| `aes_зашифровать(текст, ключ)` | AES-CBC, PKCS7, случайный IV; ключ — ровно 16, 24 или 32 байта; результат — base64 (IV в начале) |
| `aes_расшифровать(base64, ключ)` | обратная операция; неверный ключ — ошибка |
| `jwt_создать(словарь, секрет)` | JWT HS256 |
| `jwt_проверить(токен, секрет)` | полезная нагрузка (словарь) или `ложь`, если подпись неверна. **Срок действия (`exp`) не проверяется** — проверяйте сами |

Модуль не предназначен для хранения паролей (нет bcrypt/argon2) и не даёт криптостойкого генератора случайных чисел (его нет и в `случайное`).

## http

### Клиент

`http.получить(url, [тело], [заголовки])`, `http.пост(url, [тело], [заголовки])`, `http.положить(…)`, `http.удалить(…)`, `http.патч(…)`; общий вариант — `http.отправить(метод, url, [тело], [заголовки])`.

- Тело: строка отправляется как есть; **словарь или массив автоматически сериализуются в JSON** (с `Content-Type: application/json`).
- Заголовки — словарь `{"Authorization": "Bearer …"}`.
- Результат — словарь **`{статус, тело, заголовки, url}`**. Коды 4xx/5xx — **не** ошибка: проверяйте `статус`. Ошибкой считаются сетевые сбои и таймаут (8 секунд).
- Клиент обходит системный прокси и использует DNS 8.8.8.8 / 1.1.1.1.

```
пусть ответ = http.получить("https://example.com/api")
если ответ.статус == 200
    пусть данные = json.разобрать(ответ.тело)
    возгласи(данные)
конец
```

### Сервер

```
пусть app = http.приложение()

app.получить("/", запрос => "<h1>Привет</h1>")
app.получить("/api/время", запрос => {"сейчас": время.сейчас()})
app.пост("/api/эхо", слово(запрос)
    аминь {"статус": 201, "тело": запрос.json}
конец)
app.статика("/static/", "./public")

app.запустить(8080)        # блокирует выполнение
```

Методы приложения (каждый возвращает приложение — можно цепочкой):

| Метод | Описание |
|-------|----------|
| `получить(путь, обработчик)`, `пост`, `положить`, `удалить`, `патч` | маршрут для HTTP-метода |
| `маршрут(метод, путь, обработчик)` | то же с методом строкой |
| `использовать(слово)` | промежуточный обработчик: получает запрос; результат `ложь` или ошибка → ответ 403 |
| `статика(url_префикс, папка)` | раздача файлов |
| `запустить(порт)` | запуск (блокирующий); запрещён в безопасном режиме |

Пути — шаблоны Go `ServeMux`: точное совпадение, а путь с `/` на конце (`/static/`, `/`) охватывает всё поддерево. Параметров вида `/user/:id` **нет** — берите `запрос.путь` и разбирайте сами или используйте `?параметры`. Метод, не совпавший с зарегистрированным, даёт 405.

**Запрос** (аргумент обработчика) — словарь:

| Поле | Содержимое |
|------|------------|
| `метод`, `путь`, `url` | строки |
| `параметры` | query-параметры (значение — строка; при повторении — массив) |
| `заголовки` | ключи в нижнем регистре |
| `куки` | словарь |
| `тело` | тело строкой |
| `json` | разобранное тело, если `Content-Type: application/json` |
| `форма` | поля `application/x-www-form-urlencoded` |

**Ответ** (результат обработчика):

| Результат | HTTP-ответ |
|-----------|-----------|
| строка | 200, `text/html` |
| словарь/массив без поля `статус` | 200, JSON |
| словарь с `статус` | `{статус, тело, заголовки, тип, куки}`; тело-строка пишется как есть, другое — как JSON; `куки` — словарь `имя → строка` (или `{значение, путь, макс_возраст, http_only}`; `ничего` удаляет) |
| `ничего` | 204 без тела |

Простейший сервер: `http.сервер(порт, обработчик)` — один обработчик на все пути (не блокируется безопасным режимом — не полагайтесь на `--безопасный` для сетевых программ).

## шаблон

Простой шаблонизатор HTML/текста.

| Конструкция | Значение |
|-------------|----------|
| `{{имя}}`, `{{товар.цена}}` | подстановка (поля словарей/экземпляров через точку); отсутствующее значение — пусто |
| `{{если условие}}…{{иначе}}…{{конец}}` | условие: `имя`, `!имя`, `имя == "текст"`, `имя != "текст"` |
| `{{для x в список}}…{{конец}}` | цикл по массиву; `x` доступно в теле |
| `{{включить "часть.html"}}` | вставка файла (путь от папки шаблона) |

| Слово | Описание |
|-------|----------|
| `шаблон.рендер(текст, [данные])` | данные — словарь |
| `шаблон.файл(путь, [данные])` | то же из файла |
| `шаблон.экранировать(текст)` | HTML-экранирование (`<`, `>`, `&`, `"`, `'`) |

**Подстановка `{{…}}` не экранирует HTML автоматически.** Для пользовательских данных пишите `шаблон.экранировать(…)` перед рендером. Выражений и вызовов слов внутри `{{ }}` нет, только пути по данным.

```
шаблон.рендер("<ul>{{для х в список}}<li>{{х.имя}}</li>{{конец}}</ul>",
    {"список": [{"имя": "а"}, {"имя": "б"}]})
```

## бд

SQLite (встроенный драйвер, без внешних зависимостей) и PostgreSQL.

```
пусть с = бд.открыть("данные.db")          # или ":memory:"
с.выполнить("CREATE TABLE IF NOT EXISTS люди (id INTEGER PRIMARY KEY, имя TEXT, возраст INTEGER)")
с.выполнить("INSERT INTO люди (имя, возраст) VALUES (?, ?)", "Анна", 25)
для р в с.запрос("SELECT * FROM люди WHERE возраст > ?", 18)
    возгласи(р.имя)
конец
с.закрыть()
```

Подключение: `бд.открыть(путь_или_:memory:)` для SQLite; `бд.подключить(строка)` для PostgreSQL (`postgres://user:pass@host:5432/db` или DSN `host=… dbname=…`; `?` в запросах автоматически превращаются в `$1, $2, …`).

Методы соединения:

| Метод | Результат |
|-------|-----------|
| `выполнить(sql, параметры…)` | `{вставлено_id, затронуто}` |
| `запрос(sql, параметры…)` | массив словарей (ключи — имена колонок) |
| `строка(sql, параметры…)` | первая строка (словарь) или `ничего` |
| `значение(sql, параметры…)` | первое поле первой строки или `ничего` |
| `транзакция(слово(тх) … конец)` | вызывает слово с «транзакционным» соединением (`тх.выполнить`, `тх.запрос`, `тх.строка`, `тх.значение`); если слово вернуло ошибку — откат, иначе фиксация; возвращает результат слова |
| `подготовить(sql)` | подготовленный запрос: `.выполнить(…)`, `.запрос(…)`, `.закрыть()` |
| `вставить_много(таблица, [колонки], [[значения], …])` | пакетная вставка; `{затронуто}` |
| `таблицы()` | массив имён таблиц |
| `колонки(таблица)` | массив `{имя, тип, обязательное, первичный_ключ, по_умолчанию}` |
| `мигрировать(версия, sql)` | применяет SQL один раз для номера версии; `истина` — применено, `ложь` — уже было |
| `версия()` | максимальная применённая версия (0 — нет) |
| `закрыть()` | закрыть соединение |

Всегда используйте параметры `?`, а не склейку строк (защита от SQL-инъекций). Модуль `бд` не ограничивается безопасным режимом по пути файла базы.

## вс

WebSocket.

```
пусть сокет = вс.подключить("wss://echo.example/ws")
сокет.отправить("привет")
возгласи(сокет.получить())
сокет.закрыть()
```

Клиент (`вс.подключить(url)`, нужен `ws://` или `wss://`):

| Метод | Описание |
|-------|----------|
| `отправить(текст)`, `отправить_json(значение)` | отправка |
| `получить()` | блокирующее чтение одного сообщения (строка); при закрытии — `ничего` |
| `слушать(n, обработчик)` | прочитать до `n` сообщений, вызывая `обработчик(сообщение)`; если обработчик вернул `ложь` — остановиться |
| `таймаут(секунды)` | таймаут чтения |
| `открыт?()` | жив ли сокет |
| `закрыть()` | |

Сервер: `вс.сервер(порт, обработчик)` — для каждого клиента вызывается `обработчик(клиент)`, у клиента методы `отправить`, `получить`, `открыт?`, `закрыть`.

```
вс.сервер(8081, слово(клиент)
    доколе клиент.открыт?()
        пусть сообщение = клиент.получить()
        если сообщение == ничего: прерви
        клиент.отправить("Эхо: " + сообщение)
    конец
конец)
```

## веб

Встроенный веб-фреймворк с маршрутизацией (`/users/:id`, `/files/*путь`), группами маршрутов, middleware и тестированием без открытия порта.

```
пусть app = веб.приложение()
app.использовать(веб.cors("*"))
app.использовать(веб.логгер())

пусть api = app.группа("/api")
api.получить("/users/:id", слово(запрос)
    аминь веб.json({"id": запрос.парам("id"), "lang": запрос.арг("lang", "ru")})
конец)

# Внутрипроцессный тест без сети:
пусть r = app.обработать("GET", "/api/users/42?lang=en")
возгласи(r["статус"], r["тело"])

# Запуск сервера:
# app.запустить(8080)
```

- Методы приложения и группы: `получить`, `пост`, `положить`, `удалить`, `патч`, `маршрут(метод, путь, обработчик)`, `группа(префикс)`, `использовать(middleware)`, `при_ошибке(обработчик)`, `статика(url, папка)`, `обработать(метод, путь, [тело], [заголовки])`, `запустить(порт)`.
- Ответы: `веб.текст(s, [статус])`, `веб.html(s, [статус])`, `веб.json(v, [статус])`, `веб.редирект(url, [статус])`, `веб.ошибка(статус, текст)`, `веб.кука(ответ, имя, знач, [опции])`.
- Встроенные middleware: `веб.cors([источник])`, `веб.логгер()`.
