# 01. Начало

## Установка

### Готовые сборки и пакетные менеджеры

Релизы публикуются по тегу `v*` через GitHub Actions + goreleaser: Windows (amd64), Linux и macOS (amd64, arm64), включая пакеты `.deb`/`.rpm`, Homebrew и Scoop.

- **Одной командой (Linux / macOS):** `curl -fsSL https://raw.githubusercontent.com/zavet-lang/zavet/main/install.sh | sh`
- **Homebrew (macOS / Linux):** `brew install zavet-lang/tap/zavet` (формула также в `packaging/homebrew/zavet.rb`)
- **Scoop (Windows):** `scoop bucket add zavet https://github.com/zavet-lang/scoop-bucket && scoop install zavet` (манифест в `packaging/scoop/zavet.json`)
- **APT / Debian / Ubuntu:** скачайте `.deb` из GitHub Releases и выполните `sudo apt install ./zavet_*.deb` (скрипт локальной сборки: `packaging/apt/build-deb.sh`)

> **Писание.** Встроенные `стих(...)` и `писание(...)` читают Синодальный перевод из файла `data/bible/synodal.json`. Он не вшит в бинарник: положите папку `data/bible/` рядом с запускаемым файлом, в текущую папку или на один–два уровня выше исполняемого файла (поиск идёт именно в таком порядке). Без файла остальной язык работает, а `стих` сообщит: «не найден свиток data/bible/synodal.json».

### Сборка из исходников

Нужен Go (см. `go.mod`).

```
go build -ldflags "-X main.Version=1.1.0" -o zavet.exe .       # Windows
go build -ldflags "-X main.Version=1.1.0" -o zavet .           # Linux / macOS
```

То же делает `make build`. Проверка:

```
.\zavet.exe версия
Завет v1.1.0
```

Тесты: `go test ./...` (golden-тесты `tests/cases/*.молитва` сравнивают вывод с `*.expected`).

## Запуск программ

```
zavet файл.молитва              # выполнить файл
zavet запустить                 # выполнить точку входа проекта (пакет.json)
zavet запустить файл.молитва    # то же, что zavet файл.молитва
zavet                           # интерактивный режим (REPL)
zavet помощь                    # справка
zavet версия                    # версия
```

Глобальные флаги можно ставить где угодно среди аргументов:

| Флаг | Действие |
|------|----------|
| `--безопасный` (`--safe`) | песочница: файлы только внутри текущей папки, без процессов, записи, серверов |
| `--разрешить-хост=host` (`--allow-host=`) | разрешить исходящий HTTP к хосту (только вместе с `--безопасный`; флаг можно повторять) |
| `--vm` | исполнить байткод-VM (подмножество языка; иначе откат к интерпретатору) |

Подробнее — в [главе 06](06_ИНСТРУМЕНТЫ.md).

Код возврата: `0` — успех, `1` — необработанная ошибка выполнения. Ошибки разбора программы выводятся списком `❌ Ошибки парсинга:` до начала выполнения (в этом случае ни одна строка программы не исполняется).

## Первая программа

`привет.молитва`:

```
возгласи("Мир вам!")
возгласи(стих("Ин", 1, 1))
```

```
> zavet привет.молитва
Мир вам!
Иоанн 1:1 — В начале было Слово, и Слово было у Бога, и Слово было Бог.
```

`возгласи(...)` печатает все аргументы **подряд без разделителей** и добавляет перевод строки:

```
возгласи("a", 1, истина)       # a1истина
```

## REPL

`zavet` без аргументов открывает интерактивный режим:

```
Введите 'выход' или 'exit' для выхода

>>> пусть x = 40
>>> x + 2
42
>>> слово удвой(n): n * 2
>>> удвой(x)
80
>>> выход
До свидания!
```

Особенности:

- каждая строка вводится целиком (многострочные блоки через REPL писать неудобно — используйте файлы или однострочную форму `слово f(x): …`);
- результат выражения печатается, если он не `ничего`;
- окружение сохраняется между строками.

## Структура проекта

Создать проект:

```
zavet инит мой_проект
cd мой_проект
zavet запустить
```

`zavet инит` создаёт:

```
мой_проект/
├── пакет.json          # манифест
├── главный.молитва     # точка входа
└── .gitignore          # исключает папку пакеты/
```

Папка `пакеты/` появляется при установке зависимостей. Подробности — в [главе 04](04_ОШИБКИ_ТЕСТЫ_МОДУЛИ.md#пакеты) и [главе 06](06_ИНСТРУМЕНТЫ.md#менеджер-пакетов).

## Структура репозитория интерпретатора

| Путь | Назначение |
|------|-----------|
| `main.go` | CLI: команды, флаги, REPL |
| `lexer/` | лексер (токены, ключевые слова) |
| `parser/` | парсер → AST (`ast/`) |
| `interpreter/` | вычислитель, встроенные слова, стандартная библиотека |
| `interpreter/vm/` | байткод-VM (подмножество) |
| `bible/`, `data/bible/` | Синодальный перевод |
| `formatter/`, `linter/` | `zavet формат`, `zavet проверить` |
| `lsp/`, `mcp/` | языковой сервер и MCP-сервер |
| `pkgmgr/` | менеджер пакетов |
| `vscode-extension/` | расширение для VS Code / Cursor |
| `examples/` | примеры (`01_…`–`22_…`, `писание`, модульный браузер) |
| `tests/` | golden-тесты |
