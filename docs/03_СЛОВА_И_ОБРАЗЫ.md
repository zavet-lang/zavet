## Слова (функции)

```
слово сложить(а, б)
    аминь а + б
конец

возгласи(сложить(2, 3))     # 5
```

**Однострочная форма** — `:` и одно выражение; его значение возвращается автоматически:

```
слово квадрат(x): x * x
слово факториал(n): если n <= 1: 1 иначе: n * факториал(n - 1)
```

**Анонимное слово** — без имени, как значение:

```
пусть вычислить = слово(а, б)
    аминь а + б
конец
возгласи(вычислить(1, 2))   # 3

сортировать([3, 1, 2], слово(а, б): а > б)    # [1, 2, 3]
```

(Компаратор `сортировать` возвращает истину, если `а` и `б` нужно **поменять местами**; `а > б` даёт порядок по возрастанию.)

Именованное слово появляется в текущей области видимости сразу при выполнении определения (до этого момента вызвать его нельзя: определяйте слова выше места вызова).

**Рекурсия** ограничена глубиной **1000** вызовов; при превышении — ошибка «превышена максимальная глубина рекурсии» с подсказкой.

## Параметры

```
слово привет(кому = "мир")            # значение по умолчанию
    аминь "Привет, {кому}!"
конец
привет()                              # Привет, мир!
привет("Аня")                         # Привет, Аня!

слово сумма(...числа)                 # rest: остальные аргументы в массив
    аминь свернуть(числа, (a, b) => a + b, 0)
конец
сумма(1, 2, 3)                        # 6

слово f(а, б = 10, ...ещё): "{а} {б} {ещё}"
f(1)              # 1 10 []
f(1, 2, 3, 4)     # 1 2 [3, 4]
```

Правила:

- Недостающие аргументы без значения по умолчанию становятся `ничего`; лишние аргументы игнорируются (кроме `...rest`).
- Значения по умолчанию вычисляются при **каждом** вызове в окружении, где слово определено, и могут быть выражениями.
- `...имя` допускается только последним параметром.
- В вызове можно «раскрыть» массив в аргументы: `сумма(...[1, 2, 3])`.
- Именованных аргументов нет.

## Возврат значений

```
слово модуль(n)
    если n < 0
        аминь -n
    конец
    аминь n
конец
```

- `аминь значение` завершает слово. Голого `аминь` без значения нет — пишите `аминь ничего`.
- Несколько значений через запятую упаковываются в массив: `аминь a, b` ⇒ `[a, b]`; принимайте через деструктуризацию: `пусть [x, y] = f()`.
- Если `аминь` не встретился, результатом слова становится значение **последней выполненной инструкции-выражения** тела:

```
слово блок(x)
    пусть y = x * 2
    y + 1                  # результат слова
конец
блок(5)                    # 11
```

Не полагайтесь на это в длинных телах: явный `аминь` читается лучше.

## Замыкания и слова как значения

Слово запоминает область, в которой было создано:

```
слово счётчик()
    измени n = 0
    аминь слово()
        n += 1
        аминь n
    конец
конец

пусть с = счётчик()
с()                     # 1
с()                     # 2
```

Слова — обычные значения: их можно хранить в переменных, массивах и словарях, передавать и возвращать.

```
слово применить(ф, х): ф(х)
применить(х => х + 1, 1)      # 2

пусть дл = длина              # встроенные слова — тоже значения
дл("абв")                     # 3

пусть операции = {"плюс": (a, b) => a + b, "минус": (a, b) => a - b}
операции.плюс(5, 3)           # 8
```

Вызов слова из словаря (`операции.плюс(5, 3)`) идёт **без** `это`: словарь — не объект. Для методов с `это` используйте [образы](#образы-классы).

## Лямбды

Лямбда — слово из одного выражения:

```
x => x * 2                 # один параметр
(a, b) => a + b            # несколько
() => 42                   # без параметров
```

Лямбда не может содержать блок инструкций; для этого используйте `слово(…) … конец`. Лямбды удобны с `фильтр`, `преобразовать`, `свернуть`, `сортировать`, `найти`, `все`, `любой`.

## Вызов в виде метода

Запись `значение.имя(аргументы)` для не-экземпляров означает вызов слова `имя(значение, аргументы)`. Слово ищется сначала среди **ваших** слов и переменных, затем среди встроенных:

```
"привет".верхний()                 # верхний("привет")
возгласи([3, 1, 2].сортировать())            # сортировать([3, 1, 2])
возгласи([1, 2, 3].длина())                  # 3

слово удвоить(х): х * 2
5.удвоить()                        # 10
```

Это позволяет писать цепочки без пайпа:

```
возгласи([1, 2, 3, 4].фильтр(x => x > 1).преобразовать(x => x * 10))    # [20, 30, 40]
```

## Декораторы

Декоратор — слово, принимающее слово и возвращающее слово. Записывается `@имя` перед определением:

```
слово логировать(f)
    слово обёртка(x)
        возгласи("вход: " + строка(x))
        пусть результат = f(x)
        возгласи("выход: " + строка(результат))
        аминь результат
    конец
    аминь обёртка
конец

@логировать
слово квадрат(x): x * x

квадрат(5)       # вход: 5 / выход: 25
```

Несколько декораторов применяются снизу вверх: `@a @b слово f` — это `a(b(f))`.

## Генераторы

Слово, в теле которого есть `выдать`, при вызове возвращает **генератор** (тип `GENERATOR`) — ленивую последовательность. Тело выполняется порциями: до очередного `выдать`.

```
слово натуральные()
    измени n = 0
    доколе истина
        n += 1
        выдать n
    конец
конец

возгласи(взять(натуральные(), 5))      # [1, 2, 3, 4, 5]
```

Потребление:

| Способ | Пример |
|--------|--------|
| цикл `для` | `для x в натуральные(): …` (бесконечный генератор прерывайте `прерви`) |
| `взять(ген, N)` | первые N значений массивом; затем генератор закрывается |

Генератор может быть конечным:

```
слово квадраты(n)
    для i от 1 до n: выдать i * i
конец
взять(квадраты(10), 3)     # [1, 4, 9]
```

Каждый вызов слова создаёт новый независимый генератор. Реализован на горутинах: незавершённые бесконечные генераторы освобождаются при `взять` и при выходе из цикла.

## Асинхронность

`асинх выражение` запускает выражение в фоновой горутине и сразу возвращает **будущее** (`FUTURE`). `ждать будущее` блокируется до результата.

```
слово тяжёлая(n): n * 2

пусть а = асинх тяжёлая(1)
пусть б = асинх тяжёлая(2)
возгласи(ждать а)              # 2
возгласи(все_ждать([а, б]))    # [2, 4]
возгласи(готово(а))            # истина — результат уже есть?
```

- `ждать` не-будущего значения просто возвращает его.
- `все_ждать(массив)` ждёт все будущие из массива, возвращает массив результатов.
- `готово(будущее)` — неблокирующая проверка.
- Ошибка внутри `асинх` не роняет программу сразу: она всплывёт в точке `ждать`, где её можно поймать через `попытка … поймать`.
- Фоновые задачи **делят** окружение с основной программой без блокировок: не изменяйте из них одни и те же переменные одновременно.

## Образы (классы)

```
образ Точка
    слово создать(x, y)
        это.x = x
        это.y = y
    конец

    слово длина()
        аминь корень(это.x * это.x + это.y * это.y)
    конец

    слово сдвинуть(dx, dy)
        это.x += dx
        это.y += dy
        аминь это
    конец
конец

пусть p = Точка(3, 4)
возгласи(p.x)                  # 3
возгласи(p.длина())            # 5.0
p.сдвинуть(1, 1).сдвинуть(1, 1)
возгласи(p.x)                  # 5
```

### Создание экземпляра

Два равноправных способа:

```
пусть p1 = Точка(3, 4)
пусть p2 = новый Точка(3, 4)
```

Образ **без** конструктора и без родителя нельзя вызвать как `Образ()` — для него пишите `новый Образ()`:

```
образ Пустой
    слово привет(): "привет"
конец
новый Пустой().привет()
```

### Конструктор

Метод `создать` (внутри хранится под именем `инициализация`; оба имени взаимозаменяемы). Параметры могут иметь значения по умолчанию и `...rest`. Результат конструктора игнорируется, ошибка в нём прерывает создание.

### `это` и поля

- Внутри метода `это` — текущий экземпляр.
- Поля не объявляются: они создаются присваиванием `это.поле = значение` (в любом методе) или снаружи `объект.поле = значение`. Чтение отсутствующего поля даёт `ничего`.
- Есть и функция `установить(объект, "имя", значение)`.
- Закрытых (приватных) полей нет: всё доступно снаружи.

### Методы

- Метод вызывается как `объект.метод(…)`; `это` подставляется автоматически.
- Метод без скобок — **связанный метод** (`BOUND_METHOD`): он помнит `это` и его можно передать как значение:

```
пусть удвой = p.длина        # связан с p
p.x = 100
возгласи(удвой())            # считает по p, уже с x = 100
```

- Методы одного образа вызывают друг друга через `это.метод()`.
- Доступа к образу целиком (`Точка.метод`) как к «статическому» нет; слово `статичная` зарезервировано, но не реализовано.

Тип экземпляра — `INSTANCE`; `возгласи(экземпляр)` печатает `<экземпляр>`. Для читаемого вывода определяйте свой метод (например, `в_строку()`).

## Наследование

```
образ Животное
    слово создать(имя, возраст = 1)
        это.имя = имя
        это.возраст = возраст
    конец
    слово голос(): "{это.имя}: звук"
    слово дышит(): "дышит"
конец

образ Кот наследует Животное
    слово голос(): "{это.имя}: мяу"
конец

образ Собака наследует Животное
    слово создать(имя, порода)
        родитель.создать(имя, 5)          # конструктор предка
        это.порода = порода
    конец
    слово голос(): "{это.имя} ({это.порода}): гав > " + родитель.голос()
конец

пусть барсик = Кот("Барсик")
пусть бобик = Собака("Бобик", "Овчарка")
возгласи(барсик.голос())     # Барсик: мяу
возгласи(бобик.голос())      # Бобик (Овчарка): гав > Бобик: звук
возгласи(бобик.дышит())      # дышит (унаследовано)
возгласи(бобик.возраст)      # 5
```

Правила:

- Синтаксис: `образ Имя наследует Родитель`. Родитель один; он должен быть определён выше.
- Цепочка наследования **любой глубины** (`образ В наследует Б`, `образ Б наследует А`): метод ищется у экземпляра, затем в его образе, затем у родителя, деда и т. д.
- Если у образа нет своего `создать`, используется конструктор ближайшего предка.
- **`родитель`** внутри любого метода (не только конструктора) — образ, стоящий **над тем, в котором определён метод**. `родитель.метод(…)` вызывает версию предка на текущем `это`, `родитель.создать(…)` — конструктор предка.
- Переопределение — просто метод с тем же именем в потомке.
- Полиморфизм работает «по-утиному»: важно лишь, что у объекта есть нужный метод.

```
для ж в [барсик, бобик]
    возгласи(ж.голос())
конец
```

## Перечисления: `род`

```
род Цвет
    красный
    зелёный
    синий
конец

возгласи(Цвет.красный)             # красный
пусть выбор = Цвет.зелёный
если выбор == Цвет.зелёный: возгласи("зелёный")

пусть имя = разбери выбор
    когда Цвет.красный: "тревога"
    когда Цвет.зелёный: "ок"
    иначе: "неизвестно"
конец
```

Каждый член — строка с именем члена (`Цвет.красный == "красный"`), а сам `Цвет` — словарь (`тип(Цвет)` → `HASH`). Список членов: `ключи(Цвет)`. Значений, отличных от имени, и методов у перечисления нет.
