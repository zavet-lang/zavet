## Лексика

**Файлы** — UTF-8, расширение `.молитва`.

**Комментарии** — от `#` до конца строки. Внутри строкового литерала `#` — обычный символ.

```
# это комментарий
возгласи("#не комментарий")   # а это комментарий
```

**Разделители инструкций** — перевод строки. Точка с запятой не нужна.

**Идентификаторы** — буквы (Unicode: кириллица, латиница), цифры и `_`, начинаться с цифры не могут. Регистр различается. Идентификатор может заканчиваться на `?` (например, `открыт?`), если сразу после `?` нет точки — иначе `x?.y` читалось бы неоднозначно.

**Ключевые слова** (46) нельзя использовать как имена:

| Группа | Слова |
|--------|-------|
| Объявления | `пусть` `измени` `слово` `образ` `род` `тест` |
| Управление | `если` `иначеесли` `иначе` `для` `от` `до` `по` `в` `доколе` `повтори` `раз` `прерви` `продолжи` `разбери` `когда` `конец` |
| Функции | `аминь` `выдать` `асинх` `ждать` |
| Образы | `новый` `наследует` `родитель` `это` `статичная` |
| Значения | `истина` `ложь` `ничего` |
| Логика | `и` `или` `не` |
| Ошибки | `попытка` `поймать` `всегда` `бросить` `проверить` |
| Модули | `приими` `из` `как` `открой` |

> ⚠ Короткие слова `и`, `в`, `от`, `до`, `по`, `из`, `как`, `раз`, `не`, `род` — ключевые, поэтому, например, переменную `в` или `и` завести нельзя (`пусть в = 1` — ошибка разбора). Выбирайте имена подлиннее.

**Числовые литералы:** `42`, `3.14`. Шестнадцатеричной записи (`0x10`) и экспоненты (`1e3`) нет.

**Строковые литералы:** `"…"`, `'…'`, `"""…"""` — см. [Строки](#строки).

**Операторы и знаки:** `+ - * / // % == != < > <= >= = += -= *= /= => |> ?? ?. ? : .. ... . , ( ) [ ] { } @ !`.

## Значения и типы

Функция `тип(x)` возвращает имя типа строкой:

| Значение | `тип(...)` | Примеры |
|----------|-----------|---------|
| целое (int64) | `INTEGER` | `42`, `-7` |
| дробное (float64) | `FLOAT` | `3.14`, `0.5` |
| строка | `STRING` | `"привет"` |
| булево | `BOOLEAN` | `истина`, `ложь` |
| ничего | `NULL` | `ничего` |
| массив | `ARRAY` | `[1, 2, 3]` |
| словарь | `HASH` | `{"а": 1}` |
| слово | `FUNCTION` | `слово f() … конец`, `x => x` |
| встроенное слово | `BUILTIN` | `длина` |
| метод экземпляра | `BOUND_METHOD` | `объект.метод` |
| экземпляр образа | `INSTANCE` | `Точка(1, 2)` |
| генератор | `GENERATOR` | результат вызова слова с `выдать` |
| будущее | `FUTURE` | результат `асинх …` |
| значение ошибки | `ERROR_VALUE` | `e` в `поймать e` |

Образы (`образ`) и перечисления (`род`) внутри — это словари (`HASH`).

### Истинность

Ложными считаются **только** `ложь` и `ничего`. Всё остальное — истина, включая `0`, `""` и `[]`.

```
если 0: возгласи("ноль — это истина")
если "": возгласи("пустая строка — тоже истина")
```

`ничего == ложь` даёт `истина` (сознательная совместимость: «нет/пусто»).

### Печать значений

`возгласи` и `строка(x)` показывают значения так:

| Тип | Вид |
|-----|-----|
| целое | `42` |
| дробное | `3.5`, а целое дробное — `3.0` |
| булево | `истина` / `ложь` |
| ничего | `ничего` |
| массив | `[1, 2, а]` — строки **без** кавычек |
| словарь | `{имя: Аня, возраст: 30}` |
| слово | `слово(...)` |

## Связывания: `пусть` и `измени`

```
пусть имя = "Аня"       # неизменяемая связь
измени счёт = 0          # изменяемая переменная
счёт = счёт + 1
счёт += 5
```

- `пусть` — связь нельзя переприсвоить: `имя = "Борис"` даёт ошибку «сын мой, «имя» сотворено словом «пусть» и не меняется». Но **содержимое** изменяемого значения (массив, словарь, экземпляр) менять можно: `пусть список = []; список.добавить(1)` — допустимо.
- Повторный `пусть` с тем же именем в той же области просто заменяет связь (`пусть а = 1; пусть а = 2` → `а` равно 2).
- `измени` внутри функции создаёт **локальную** изменяемую переменную и не блокируется внешним `пусть` с тем же именем (затенение):

```
пусть x = 1
слово внутри()
    измени x = 2      # локальная переменная, внешний x не тронут
    аминь x
конец
возгласи(внутри())    # 2
возгласи(x)           # 1
```

- Присваивание `имя = значение` изменяет **ближайшую существующую** переменную, поднимаясь по областям видимости. Если имя нигде не объявлено — ошибка «сын мой, «имя» ещё не сотворено».
- Составные присваивания: `+=`, `-=`, `*=`, `/=` (для имён, `obj.поле`, `массив[i]`).

**Области видимости** создают: тело слова, тело метода, блок `попытка/поймать` (для переменной ошибки). Блоки `если`, `для`, `доколе`, `повтори` **не** создают новой области: переменные, объявленные внутри, видны после блока.

**Множественное объявление:**

```
пусть а, б = [1, 2]          # справа массив
пусть х, у = 10, 20          # справа несколько значений через запятую
измени м, н = [3, 4]
```

**Опциональные аннотации типов:**

Типы необязательны — код без них работает как обычно. Когда аннотация указана, интерпретатор проверяет значение во время выполнения:

```
пусть x: целое = 42
измени имя: строка? = ничего      # «?» допускает ничего

слово сложить(a: целое, b: целое) -> целое
    аминь a + b
конец
```

Встроенные имена типов: `целое`, `дробное`, `число` (`целое` или `дробное`), `строка`, `булево`, `массив`, `словарь`, `слово`, `ничего`, `любой`, а также имена пользовательских образов (с учётом наследования) и nullable-форма `Тип?`. `zavet формат` и `zavet док` сохраняют аннотации.

Это сокращение деструктуризации (см. [ниже](#деструктуризация-и-spread)).

## Операторы

### Арифметика

| Оператор | Значение | Примеры |
|----------|----------|---------|
| `+` | сложение / склейка строк | `1 + 2` → `3`; `"а" + 1` → `"а1"` |
| `-` | вычитание, унарный минус | `5 - 2`, `-x` |
| `*` | умножение | `3 * 4` |
| `/` | деление | `8 / 2` → `4` (целое); `7 / 2` → `3.5` |
| `//` | целочисленное деление (усечение к нулю) | `7 // 2` → `3`, `-7 // 2` → `-3` |
| `%` | остаток (знак как у делимого) | `7 % 3` → `1`, `-5 % 3` → `-2` |

- Деление целых даёт целое, если делится нацело, иначе дробное.
- Деление на ноль — ошибка «деление на ноль».
- Смешение целого и дробного даёт дробное.
- Оператора возведения в степень нет: используйте `степень(основание, показатель)`.
- Целые — `int64` (при переполнении «заворачиваются»).
- `+` с хотя бы одной строкой склеивает: числа, булевы, `ничего`, массивы приводятся через `строка(...)`. Дробное в склейке печатается компактно (`"x" + 3.0` → `"x3"`, а `возгласи(3.0)` → `3.0`).

### Сравнение

`==` и `!=` работают для всех типов и сравнивают **по значению, глубоко**: массивы и словари равны, если равны все элементы. `5 == 5.0` — истина; значения разных типов (кроме числа/числа и `ничего`/`ложь`) не равны.

`<`, `>`, `<=`, `>=` работают для чисел и для строк (строки — лексикографически). Для других типов — ошибка «неизвестный оператор».

### Логика

| Оператор | Значение |
|----------|----------|
| `и` | логическое И |
| `или` | логическое ИЛИ |
| `не x` / `!x` | отрицание |
| `a ?? b` | `b`, если `a` равно `ничего` или `ложь`, иначе `a` (правая часть вычисляется лениво) |

`и` и `или` возвращают **булево** (`истина`/`ложь`), а не один из операндов, и вычисляют **оба** операнда (короткого замыкания нет). Для безопасных проверок используйте вложенные `если` или `??`.

### Доступ и вызов

| Запись | Смысл |
|--------|-------|
| `x.имя` | поле словаря / свойство экземпляра / модуль |
| `x.имя(…)` | вызов метода или функции модуля |
| `x?.имя`, `x?.имя(…)` | то же, но если `x` равно `ничего` — результат `ложь` (равна `ничего`) без ошибки |
| `x[i]` | индекс массива/строки или ключ словаря |
| `x[a:b]` | срез |
| `f(…)` | вызов |

### Пайп

`x |> f` — это `f(x)`; `x |> f(a, b)` — это `f(x, a, b)`:

```
пусть результат = [1, 2, 3, 4, 5, 6]
    |> фильтр(x => x % 2 == 0)
    |> преобразовать(x => x * x)
возгласи(результат)             # [4, 16, 36]
```

### Диапазон

`a..b` — массив целых от `a` до `b - 1` (правая граница **не** включается):

```
возгласи(0..5)                  # [0, 1, 2, 3, 4]
для i в 0..3: возгласи(i)
```

У `..` тот же приоритет, что у `+`/`-`, поэтому арифметику в границах берите в скобки: `0..(n + 1)`.

### Тернарный оператор

`условие ? а : б` — краткая форма. Идиоматичнее использовать `если` как выражение:

```
возгласи(5 > 3 ? "да" : "нет")
пусть знак = если x >= 0: "плюс" иначе: "минус"
```

### Приоритет (от низкого к высокому)

| № | Операторы |
|---|-----------|
| 1 | `=>` (лямбда) |
| 2 | `\|>` |
| 3 | `? :` |
| 4 | `или`, `??` |
| 5 | `и` |
| 6 | `==`, `!=` |
| 7 | `<`, `>`, `<=`, `>=` |
| 8 | `+`, `-`, `..` |
| 9 | `*`, `/`, `//`, `%` |
| 10 | унарные `-`, `не`, `!` |
| 11 | вызов `()`, `.`, `?.` |
| 12 | индекс `[]` |

Скобки `( )` меняют порядок.

## Строки

Строки — последовательности Unicode-символов; `длина("привет")` — `6`, индексы считаются **символами**, а не байтами.

### Литералы

```
"двойные кавычки — с интерполяцией {1 + 2}"
'одинарные кавычки — без интерполяции {не вычисляется}'
"""многострочная
строка"""
```

Экранирование: `\n`, `\t`, `\r`, `\b` (Backspace), `\"`, `\'`, `\\`. Любая другая `\x` даёт просто `x` (обратный слеш отбрасывается — для регулярных выражений удваивайте: `"\\d+"`).

### Интерполяция

В строке с `"` (и в `"""`) выражение в `{…}` вычисляется и подставляется:

```
пусть имя = "Аня"
возгласи("Привет, {имя}! 2 + 3 = {2 + 3}")     # Привет, Аня! 2 + 3 = 5
возгласи("Длина: {длина(имя)}, поле: {человек.имя}")
```

Если содержимое скобок **не разбирается** как выражение (`{{имя}}` для шаблонов, `{color: red}` в CSS, JSON), скобки остаются как есть. Ошибка в вычисляемом выражении (например, неизвестная переменная) — это уже ошибка выполнения.

Пустые `{}` остаются литералом.

### Операции

```
"а" + "б"                   # склейка
"привет"[0]                 # "п"
"привет"[-1]                # "т"
"привет"[1:4]               # "рив"
"привет"[:3]                # "при"
"привет"[3:]                # "вет"
"привет" < "ура"            # сравнение
для с в "abc": возгласи(с)  # перебор символов
```

Индекс строки за границами возвращает `ничего` (а не ошибку).

Богатый набор операций — во встроенных словах: `разделить`, `соединить`, `заменить`, `верхний`, `нижний`, `обрезать`, `подстрока`, `содержит`, `начинается_с`, `заканчивается_на`, `повторить`, `найти`. Они вызываются и как функции, и как методы: `"a,b".разделить(",")`. См. [главу 05](05_ВСТРОЕННЫЕ.md).

## Массивы

```
пусть а = [1, 2, 3]
пусть пустой = []
а[0]                 # 1
а[-1]                # 3 (с конца)
а[1:3]               # [2, 3]
а[0] = 10            # присваивание по индексу
длина(а)             # 3
возгласи([...а, 4, 5])         # spread: [10, 2, 3, 4, 5]
```

- Индекс за границами — ошибка «индекс N вне пределов стана». Присваивание по индексу тоже не расширяет массив.
- Массивы **изменяемы** и передаются по ссылке; встроенные `добавить`, `вставить`, `удалить`, `сортировать`, `реверс` меняют массив на месте.
- Срез создаёт новый массив; границы вне массива обрезаются.

### Генераторы списков

```
пусть числа = [1, 2, 3, 4, 5, 6]
возгласи([x * x для x в числа])                  # [1, 4, 9, 16, 25, 36]
возгласи([x * x для x в числа если x % 2 == 0])  # [4, 16, 36]
возгласи([i * 2 для i в 0..4])                   # [0, 2, 4, 6]
```

Перебирать можно только массив (в том числе полученный через `..` и `диапазон`).

### Многомерные массивы

```
пусть м = [[1, 2], [3, 4]]
м[1][0] = 99          # [[1, 2], [99, 4]]
```

## Словари

Упорядоченные (по порядку вставки) пары «ключ → значение». Ключи — строки, целые или булевы.

```
пусть человек = {"имя": "Иван", "возраст": 30}
человек["имя"]               # "Иван"
человек.имя                  # то же самое
человек["город"] = "Москва"  # добавить/изменить
человек.email = "i@mail.ru"  # то же через точку
человек.нет                  # ничего (отсутствующий ключ)
длина(человек)               # 4
```

Работа с ключами и значениями:

```
ключи(человек)                    # ["имя", "возраст", "город", "email"]
значения(человек)                 # ["Иван", 30, "Москва", "i@mail.ru"]
получить(человек, "нет", 0)       # 0 — значение по умолчанию
содержит(человек, "имя")          # истина — есть ли ключ
```

> **Перебор.** `для x в словарь` даёт **значения**, а `для i, x в словарь` — **номер позиции** `i` и значение `x` (не ключ!). Чтобы получить пары, перебирайте `ключи(словарь)`:
>
> ```
> для к в ключи(человек)
>     возгласи("{к} = {человек[к]}")
> конец
> ```

Удаления ключа встроенным словом нет. Если нужно «убрать» ключ, соберите новый словарь без него.

## Деструктуризация и spread

### Массивы

```
пусть [a, b, ...остальные] = [10, 20, 30, 40, 50]
возгласи(a)           # 10
возгласи(b)           # 20
возгласи(остальные)   # [30, 40, 50]
```

Недостающие элементы становятся `ничего`. `...имя` собирает хвост и должен стоять последним.

### Словари

```
пусть {"имя": н, "возраст": в2} = {"имя": "Иван", "возраст": 30}
возгласи(н)           # Иван
```

Слева ключи — строковые литералы, справа — имена переменных.

### `измени`

С `измени` вместо `пусть` связи будут изменяемыми:

```
измени [x, y] = [1, 2]
x += 10               # 11
```

### Spread в вызовах и литералах

```
слово сумма3(a, b, c): a + b + c
пусть арг = [1, 2, 3]
сумма3(...арг)                  # 6
возгласи([...арг, 4])                     # [1, 2, 3, 4]
```

`...` применим только к массивам.

### Возврат нескольких значений

`аминь a, b` возвращает массив, который удобно разобрать:

```
слово мин_макс(xs): аминь мин(xs), макс(xs)
пусть [наименьшее, наибольшее] = мин_макс([3, 1, 4, 1, 5])
```

## Условия

### Блочная форма

```
если x > 0
    возгласи("плюс")
иначеесли x < 0
    возгласи("минус")
иначе
    возгласи("ноль")
конец
```

- `иначеесли` — **одно слово** (без пробела).
- `иначе если` (два слова) — это `иначе` + вложенный `если`, которому нужен собственный `конец`.
- Блок заканчивается одним `конец` на всю цепочку.

### Однострочная форма

После условия ставится `:` и одна инструкция:

```
если x > 0: возгласи("плюс") иначе: возгласи("не плюс")
```

### `если` как выражение

`если` возвращает значение выбранной ветки (последнего выражения в ней), либо `ничего`, если ни одна ветка не сработала:

```
пусть знак = если n > 0: "плюс" иначе: "минус"
слово модуль(n): если n < 0: -n иначе: n
```

## Циклы

### Счётный цикл: `для … от … до`

Границы **включаются**:

```
для i от 1 до 5
    возгласи(i)           # 1 2 3 4 5
конец

для i от 10 до 0 по -5    # 10 5 0
    возгласи(i)
конец
```

- Если `от` больше `до`, шаг по умолчанию — `-1` (счёт вниз), иначе `+1`.
- `по N` задаёт шаг (не ноль). Границы и шаг — только целые.

### Цикл по коллекции: `для … в`

```
для x в [10, 20, 30]: возгласи(x)

для i, x в ["а", "б"]          # индекс и значение
    возгласи("{i}: {x}")
конец

для с в "привет": возгласи(с)  # по символам
для x в генератор(): …         # по генератору
```

Перебирать можно массивы, словари (значения), строки и генераторы. Для чисел — `для i от … до` или `0..N`.

### Цикл с условием: `доколе`

```
измени n = 0
доколе n < 3
    возгласи(n)
    n += 1
конец

доколе истина
    если готово(): прерви
конец
```

### Цикл повторения: `повтори … раз`

```
повтори 5 раз
    возгласи("шаг")
конец

повтори 3 раз: сумма += 1       # однострочная форма
```

- Выражение счётчика вычисляется **один раз** до начала цикла и должно быть целым (`INTEGER`), иначе возникает ошибка.
- Если счётчик `<= 0`, тело выполняется `0` раз.
- Поддерживает `прерви`, `продолжи`, `аминь`, а также исполнение в байткод-VM (`--vm`).

### `прерви` и `продолжи`

- `прерви` — выйти из ближайшего цикла.
- `продолжи` — перейти к следующей итерации.

Работают в `для`, `доколе` и `повтори`. Во вложенных циклах действуют на внутренний.

## Выбор: `разбери`

```
пусть имя = разбери код
    когда 1: "один"
    когда 2: "два"
    иначе: "другое"
конец
```

- `разбери значение` сравнивает значение с образцами `когда` сверху вниз; срабатывает первый совпавший, остальные не вычисляются.
- Образцы сравниваются **по значению и по типу** для чисел, строк и булевых (`1` не совпадает с `1.0`); массивы и словари как образцы не сравниваются.
- **Стражи (guards).** Если образец — булево выражение, а выбираемое значение не булево, ветка срабатывает, когда выражение истинно:

```
пусть оценка = разбери балл
    когда балл >= 90: "A"
    когда балл >= 75: "B"
    иначе: "C"
конец
```

- `иначе` — ветка по умолчанию. Если нет ни совпадения, ни `иначе`, `разбери` возвращает `ложь`.
- `разбери` — выражение: результат ветки можно присвоить.
- С перечислениями (`род`) работает как обычно: `когда Цвет.красный: …`.
- Диапазон (`когда 90..100`) как образец **не** работает — это массив, а он не сравнивается со значением; используйте стражи.

## Блоки и однострочная форма

Почти все составные конструкции (`если`, `для`, `доколе`, `повтори`, `слово`) имеют две формы.

**Блочная** — тело на следующих строках, завершается `конец`:

```
слово квадрат(x)
    аминь x * x
конец
```

**Однострочная** — после заголовка `:` и **одна** инструкция; `конец` не нужен:

```
слово квадрат(x): x * x
для x в числа: возгласи(x)
если x > 0: возгласи("плюс")
```

В однострочной форме у слова результат выражения возвращается автоматически.

Отступы — только для читаемости (канон — 4 пробела, см. [СТИЛЬ.md](../СТИЛЬ.md)); границы блоков определяет `конец`.
