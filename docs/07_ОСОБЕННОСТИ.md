## Безопасный режим

Для запуска чужих или непроверенных скриптов:

```
zavet --безопасный скрипт.молитва
zavet --безопасный --разрешить-хост=api.example.com скрипт.молитва
```

Корень песочницы — **текущая папка** на момент запуска.

| Возможность | В безопасном режиме |
|-------------|---------------------|
| Чтение файлов (`читать_файл`, `существует_файл`, `файлы.читать/существует/список/размер/это_файл/это_дир`, `шаблон.файл`, `приими`) | только внутри песочницы |
| Запись, создание, удаление, переименование файлов и папок (`записать_файл`, `файлы.записать/добавить/удалить/переименовать/создать_дир/удалить_дир`) | **запрещено** |
| `загрузить` | запрещено |
| Процессы (`ос.запустить`, `ос.выполнить`), `ос.выход` | запрещены |
| `ос.сменить_директорию`, `ос.установить_переменную`, `ос.переменная` | запрещены |
| Исходящий HTTP/WebSocket (`http.получить/пост/…`, `вс.подключить`) | только к хостам из `--разрешить-хост=` (домен или его поддомены); без флага сеть закрыта |
| Серверы (`http.приложение().запустить`, `http.сервер`, `вс.сервер`) | запрещены |
| PostgreSQL (`бд.подключить`) | запрещён |
| SQLite (`бд.открыть`) | `":memory:"` или файл внутри песочницы (файл базы создаётся и изменяется) |
| `окно`, `ввод`, `возгласи`, `крипто`, `json`, вычисления | разрешены |

Попытка запрещённого действия — обычная ошибка выполнения (`операция «…» запрещена в безопасном режиме`), её можно поймать `попытка/поймать`.

Что режим **не** делает — не считайте его полноценной изоляцией:

- нет лимитов процессорного времени и памяти (бесконечный цикл или огромный массив ничем не ограничены; рекурсия — только глубиной 1000);
- символические ссылки внутри песочницы не разыменовываются при проверке пути;
- `окно` может открыть окно / локальный сервер на `127.0.0.1` (на Linux/macOS — браузер);
- не защищает от уязвимостей самого интерпретатора.

Для настоящей изоляции запускайте непроверенный код в контейнере или виртуальной машине.

## Байткод-VM

```
zavet --vm скрипт.молитва
```

Стековая байткод-VM с кадрами вызовов и быстрыми путями для целой арифметики. Поддерживает:

- числа, строки, булевы, `ничего`, массивы `[…]` и индексацию `a[i]` / `a[i] = v`;
- `пусть`, `измени`, присваивание `=` и составные `+= -= *= /=`;
- арифметику `+ - * / // %`, унарные `-`/`!`/`не`, логику `и`/`или` (с коротким замыканием), сравнения;
- `если/иначе`, `доколе`, `для i от a до b [по s]`, `повтори N раз`, `прерви`, `продолжи`;
- именованные `слово`, вызовы и рекурсию, `аминь`;
- встроенные `возгласи(…)` и `длина(…)`.

Любая неподдержанная конструкция (словари, образы, модули, `попытка`, лямбды, параметры по умолчанию, аннотации типов…) приводит к **откату на интерпретатор**: в stderr печатается `⚠ --vm: … — откат к интерпретатору`, программа выполняется как обычно.

### Производительность (замеры)

Стенд: Intel Core i7-7700HQ @ 2.80 GHz, Windows 11 Pro, Go 1.26.5 (`windows/amd64`), Python 3.12.10.

**Go-бенчмарки (`-benchmem`, без накладных расходов запуска процесса):**

| Бенчмарк | Движок | Время / прогон | Память | Аллокаций |
|----------|--------|----------------|--------|-----------|
| `BenchmarkVMFib20-8` (`fib(20)`) | байткод-VM | **1.64 ms** | 6 056 B | 36 |
| `BenchmarkFib20-8` (`fib(20)`) | AST + лексер/парсер | 13.66 ms | 7 715 121 B | 65 831 |
| `BenchmarkBubbleSort100-8` | AST + лексер/парсер | 4.59 ms | 24 937 B | 361 |
| `BenchmarkPrimes500-8` | AST + лексер/парсер | 0.76 ms | 192 954 B | 2 060 |

**Сквозной запуск CLI (медиана 3–5 запусков, включая старт процесса):**

| Задача | `zavet` (AST) | `zavet --vm` | `python` 3.12 | Ускорение `--vm` vs AST |
|--------|---------------|--------------|---------------|-------------------------|
| Пустой скрипт (старт процесса) | 24.2 ms | 24.7 ms | 64.3 ms | — |
| Рекурсия `fib(20)` (`= 6765`) | 43.5 ms | **25.9 ms** | 59.5 ms | 1.7× |
| Рекурсия `fib(25)` (`= 75025`) | 196.5 ms | **55.1 ms** | 95.6 ms | 3.6× |
| Рекурсия `fib(30)` (`= 832040`) | 1 923.5 ms | **243.7 ms** | 280.0 ms | **7.9×** |
| Цикл суммы `1..10^6` (`для от … до`) | 280.1 ms | **135.8 ms** | 209.5 ms | 2.1× |
| Цикл суммы `1..10^7` (`для от … до`) | 2 139.8 ms | **1 097.9 ms** | 1 290.3 ms | 1.9× |

На числовых циклах и рекурсии `--vm` быстрее AST-интерпретатора в 2–8 раз и сопоставим с CPython 3.12 (при более быстром холодном старте нативного Go-бинаря). Код со словарями, образами или модулями исполняется через AST tree-walker.

Воспроизведение: `go test ./interpreter/vm -run=NONE -bench=. -benchmem` и `go test ./tests -run=NONE -bench=. -benchmem`.

## Пределы и поведение реализации

| Тема | Поведение |
|------|-----------|
| Глубина рекурсии | 1000 вызовов, затем ошибка «превышена максимальная глубина рекурсии» |
| Целые | 64-битные со знаком; при переполнении значение **оборачивается** без ошибки (`9223372036854775807 + 1` → `-9223372036854775808`) |
| Дробные | `float64`; `0.1 + 0.2` → `0.30000000000000004`; очень большие печатаются как `1e+16` |
| Деление | `/` двух целых: целое, если делится нацело, иначе `FLOAT`; `//` — усечение к нулю; деление на ноль — ошибка для `/`, `//`, `%` |
| Сравнение `1 == 1.0` | `истина`; `"1" == 1` — `ложь` |
| Цепочка `a < b < c` | ошибка типов: сравнения левоассоциативны (`(a < b) < c`); пишите `a < b и b < c` |
| Ключи словарей | `1`, `"1"` и `истина` — разные ключи; порядок обхода — порядок вставки |
| Строки | UTF-8; `длина`, индексы, `подстрока` считают в символах (рунах); исключение — `найти(строка, подстрока)` (байты) |
| `сортировать` | пузырьком, O(n²); сравнивает только однотипные числа/строки |
| `округл` | отрицательные числа округляются неверно (см. [главу 05](05_ВСТРОЕННЫЕ.md#типы-и-преобразования)) |
| Литералы | нет `1e3`, `0x10`, `1_000` |
| Внутри `{…}` строки | выражение должно разбираться; иначе скобки остаются текстом |
| Escape-последовательности | `\n \t \r \b \" \' \\`; прочие `\x` дают `x` |
| Бесконечные генераторы | освобождаются при `взять` и при выходе из `для`; если потребитель просто бросил генератор — горутина остаётся до конца программы |
| `ввод` | читает строку из stdin; на конце ввода — `ничего` |

## Параллелизм

- `асинх` и генераторы работают на горутинах Go.
- Окружение (переменные) при этом **общее и без блокировок**: из нескольких `асинх` одновременно не изменяйте одну и ту же переменную, массив или словарь — результат непредсказуем (возможны гонки данных и даже аварийное завершение интерпретатора).
- Безопасный шаблон: каждая задача получает данные аргументами и возвращает результат; собирайте результаты через `все_ждать`.
- Интерпретатор сам по себе не потокобезопасен: вызов `окно.*` из `асинх` не поддерживается.

## Ограничения и не реализованное

- Все 46 ключевых слов языка реализованы (включая `повтори … раз` и `статичная`).
- Нет: закрытых полей, интерфейсов, множественного наследования, перегрузки операторов, именованных аргументов, оператора возведения в степень (есть `степень(a, b)`), цикла в стиле C (есть `для … от … до`, `для … в`, `доколе`, `повтори … раз`).
- Нет удаления ключа словаря встроенным словом (см. [главу 05](05_ВСТРОЕННЫЕ.md#словари)).
- Нет `приими {a, b} из …` и реэкспорта.
- Нет пользовательских типов-перечислений с методами (`род` — это словарь имён).

## Частые ловушки

| Ошибка | Причина и решение |
|--------|-------------------|
| `сын мой, «x» сотворено словом «пусть» и не меняется` | объявлена через `пусть`; нужен `измени` |
| Парсинг падает на строке с `в`, `и`, `или`, `не`, `от`, `до`, `по`, `из`, `как`, `это` | это ключевые слова: переименуйте переменную/параметр |
| `аминь` без значения | пишите `аминь ничего` |
| Строка, начинающаяся с `[` или `(`, «приклеилась» к предыдущей (ошибка парсинга или «идентификатор не найден») | перевод строки не завершает выражение: `ф()` и следом `[1, 2]` читается как индексирование. Начинайте такую строку с `пусть`/`возгласи(...)` или присваивания |
| `1e3`, `0x10` | не поддерживаются: `1000`, `16` |
| `"{...}"` ведёт себя неожиданно | в двойных кавычках `{}` — интерполяция; JSON/SQL пишите в `'…'` или `"""…"""`; `{` текстом — только если внутри не выражение |
| `"\d+"` в регулярном выражении теряет `\` | пишите `"\\d+"` (в одинарных кавычках escape-последовательности тоже обрабатываются) |
| `пусть x = 5` в цикле «не обновляется» | в цикле/функции нужен `измени` для накапливаемых значений |
| `сортировать(а)` изменила `а` | массивные слова `добавить/вставить/удалить/сортировать/реверс` работают на месте; копия — `объединить(а)` |
| `ошибка("текст")` внутри `асинх` ушла «в никуда» | ошибка всплывёт в точке `ждать` |
| В REPL блок не вводится | REPL — одна строка за раз: используйте однострочные формы |
| `найти("привет", "ве")` вернуло `6` | индекс в байтах UTF-8 |
| Ошибка в генераторе молча завершает перебор | проверяйте данные до `выдать` |
| `открой измени x` ничего не экспортирует | экспортируются `пусть`, слова, образы, роды; для изменяемого состояния — слова-аксессоры |
| Интерполяция даёт `3.0` вместо `3` | дробные печатаются с `.0`; при склейке `+` компактно: `"x" + 3.0` → `x3` |
