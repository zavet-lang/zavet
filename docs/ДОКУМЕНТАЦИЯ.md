# Завет — полная документация

**Завет** (`zavet`) — язык программирования на библейском русском. Исходники — файлы `.молитва`, в комплекте Синодальный перевод Библии (`стих("Ин", 3, 16)`). Интерпретатор написан на Go, версия — **1.1.0**.

```
слово приветствие(кому = "мир")
    аминь "Мир {кому}!"
конец

возгласи(приветствие("вам"))
возгласи(стих("Ин", 1, 1))
```

## Язык в одном экране

```
# Комментарий — от # до конца строки

пусть имя = "Аня"              # неизменяемая связь
измени счёт = 0                # изменяемая переменная
счёт += 1

пусть числа = [1, 2, 3, 4, 5]
пусть человек = {"имя": "Иван", "возраст": 30}

слово квадрат(x): x * x        # слово (функция), однострочная форма

для x в числа                  # цикл по коллекции
    если x % 2 == 0
        возгласи("{x} → {квадрат(x)}")
    конец
конец

образ Точка                    # образ (класс)
    слово создать(x, y)
        это.x = x
        это.y = y
    конец
    слово длина(): корень(это.x * это.x + это.y * это.y)
конец

возгласи(Точка(3, 4).длина())  # 5.0

попытка                        # ошибки
    бросить "беда"
поймать e
    возгласи("поймал: {e}")
конец
```

## Что такое «Завет» в цифрах

- **46 зарезервированных слов** (из них `повтори`, `раз`, `статичная` пока не реализованы — только зарезервированы).
- **Два способа исполнения:** интерпретатор по AST (полный язык) и байткод-VM (`--vm`, подмножество).
- **Встроенные слова** доступны без импорта; **модули стандартной библиотеки** — тоже без импорта (форма `приими бд из "бд"` допустима, но необязательна).
- **Менеджер пакетов** на базе git (`zavet подключить`), манифест `пакет.json`.
- **Инструменты:** форматтер, линтер, LSP-сервер, MCP-сервер, расширение для VS Code / Cursor.
