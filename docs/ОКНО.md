# Модуль «окно»

Графическое окно с **программным framebuffer**: вы сами рисуете каждый кадр прямоугольниками, текстом и иконками, читаете мышь и клавиатуру. API одинаков на всех ОС.

| Платформа | Backend |
|-----------|---------|
| Windows | нативное Win32-окно (GDI) |
| Linux / macOS | локальный HTTP-сервер + HTML5 canvas: при `окно.создать` открывается браузер на `http://127.0.0.1:порт/` |

Модуль доступен без импорта (`окно.создать(…)`). Окно **одно** на программу.

## Главный цикл

```
окно.создать(640, 480, "Заголовок")
измени x = 10
доколе окно.кадр()
    окно.очистить(20, 20, 30)
    окно.прямоугольник(x, 100, 50, 50, 80, 200, 120)
    окно.текст(10, 10, "Привет, мир", 255, 255, 255)
    если окно.клавиша("вправо"): x += 4
    если окно.клавиша("esc"): окно.закрыть()
    окно.задержка(16)
конец
```

Модель кадра:

1. `окно.кадр()` обрабатывает события ОС, выводит накопленный рисунок на экран и возвращает `истина`, пока окно открыто. Именно он делает рисунок видимым — поэтому цикл строится как `доколе окно.кадр()`.
2. Внутри цикла каждый кадр обычно начинается с `окно.очистить(…)`: он закрашивает весь буфер и сбрасывает текст и иконки предыдущего кадра.
3. `окно.задержка(мс)` ограничивает частоту кадров (16 мс ≈ 60 FPS) и продолжает обрабатывать события окна. Без неё цикл займёт весь процессор.

Состояние программы (положение, счёт) храните в переменных/словарях и обновляйте между вызовами `кадр()`.

## Рисование

Все координаты и цвета — **целые** числа (для дробных используйте `округл`). Цвет задаётся тремя аргументами `r, g, b` в диапазоне 0–255 (значения вне диапазона обрезаются).

| Функция | Аргументы | Описание |
|---------|-----------|----------|
| `создать` | `ширина, высота [, заголовок]` | создаёт окно; размеры 64…4096, иначе ошибка |
| `очистить` | `r, g, b` | заливка всего буфера; сбрасывает текст и иконки |
| `прямоугольник` | `x, y, w, h, r, g, b` | залитый прямоугольник; части за границами окна обрезаются |
| `текст` | `x, y, строка, r, g, b` | текст (левый верхний угол в `x, y`) |
| `иконка` | `x, y, имя, r, g, b` | глиф Font Awesome 6 Solid, например `"house"`; неизвестное имя — ошибка |
| `список_иконок` | — | массив всех доступных имён (`arrow-left`, `house`, `globe`, …) |
| `заголовок` | `строка` | сменить заголовок окна |
| `кадр` | — | `истина`, пока окно открыто (см. выше) |
| `задержка` | `мс` | пауза 0–60000 мс |
| `закрыть` | — | закрывает окно; следующий `кадр()` вернёт `ложь` |
| `открыто` | — | `истина`, если окно создано и не закрыто |
| `ширина`, `высота` | — | размер клиентской области |

Особенности:

- **Текст и иконки.** В Win32-окне они рисуются шрифтом Segoe UI (≈18 px) и накладываются **поверх** пикселей кадра: текст всегда над прямоугольниками, независимо от порядка вызовов. Чтобы закрыть текст фигурой, нарисуйте фигуру в следующем кадре или перенесите текст. В браузерном backend (Linux/macOS) текст и иконки точно так же накладываются поверх пикселей при формировании кадра.
- Размер шрифта не настраивается; ширину строки оценивайте приблизительно (в браузерном backend — моноширинная шрифтовая сетка 5×7).
- В браузерном backend (Linux/macOS) шрифт поддерживает ASCII и полную русскую кириллицу; распространённые иконки (`arrow-left`, `arrow-right`, `rotate-right`, `house`, `plus`, `xmark`, `lock`, `globe`, `user`, `star`, `image`, `check`) рисуются растровыми значками 12×12, остальные — рамкой-заглушкой; закрытие вкладки браузера автоматически завершает `окно.кадр()`.
- Иконки Font Awesome встроены в бинарник; при первом использовании шрифт распаковывается во временную папку `zavet-fonts`.

## Ввод

| Функция | Поведение |
|---------|-----------|
| `клавиша(имя)` | зажата ли клавиша (`истина`/`ложь`). Неизвестное имя — ошибка |
| `мышь_x()`, `мышь_y()` | координаты курсора в клиентской области |
| `мышь("лево" \| "право")` | кнопка зажата **сейчас** (по умолчанию `"лево"`) |
| `клик("лево" \| "право")` | **одноразовое** событие нажатия: `истина` один раз, затем сбрасывается |
| `колесо()` | накопленная дельта колеса (знак — направление), после чтения обнуляется |
| `символ()` | строка символов, набранных с последнего вызова; `\b` — Backspace; буфер очищается |

Допустимые имена клавиш:

| Группа | Имена |
|--------|-------|
| Стрелки | `влево`/`left`, `вправо`/`right`, `вверх`/`up`, `вниз`/`down` |
| Управление | `пробел`/`space`, `enter`/`ввод`, `esc`/`escape`/`выход`, `backspace`/`стереть`, `tab`/`таб`, `delete`/`удалить`, `ctrl`/`контроль`, `f5` |
| Буквы и цифры | одиночные символы `a`–`z`, `A`–`Z`, `0`–`9` |
| Игровые русские раскладки | `ф`, `в`, `ц`, `ы` (как A, D, W, S), `к`, `з`, `д`, `е`, `т` (как R, P, L, T, N) |

> `клавиша("a")` и `клавиша("ф")` — одна и та же физическая клавиша **A** (WASD независимо от раскладки). `клавиша("влево")` — стрелка. Это состояние «зажато», поэтому для однократных действий запоминайте предыдущее состояние самостоятельно.

Для текстового ввода (адресная строка, поле) используйте `символ()`: он учитывает раскладку и регистр.

```
измени строка = ""
доколе окно.кадр()
    пусть новое = окно.символ()
    для с в новое
        если с == "\b"
            если длина(строка) > 0: строка = подстрока(строка, 0, длина(строка) - 1)
        иначе
            строка = строка + с
        конец
    конец
    окно.очистить(30, 30, 30)
    окно.текст(10, 10, строка, 255, 255, 255)
    окно.задержка(16)
конец
```

Клики и попадание в области — арифметикой:

```
слово внутри(mx, my, x, y, w, h): mx >= x и mx < x + w и my >= y и my < y + h

если окно.клик("лево") и внутри(окно.мышь_x(), окно.мышь_y(), 10, 10, 100, 30)
    возгласи("кнопка нажата")
конец
```

## Ограничения

- Нет рисования линий, окружностей, изображений: используйте прямоугольники (в том числе тонкие — для линий).
- Нет звука и нескольких окон.
