## Операторы (от слабых к сильным)

```
=>    |>    ? :    или  ??    и    == !=    < > <= >=    + - ..    * / // %    - не !    () . ?. []
```

`/` — деление (точное → целое, иначе дробное), `//` — целое, `%` — остаток, `??` — значение по умолчанию для `ничего`, `?.` — безопасный доступ, `|>` — конвейер: `x |> f(a)` = `f(x, a)`. Ложны только `ложь` и `ничего`.
