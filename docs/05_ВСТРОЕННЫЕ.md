# 05. Встроенные слова

Встроенные слова доступны всегда, без импорта. Все они вызываются и как функции, и «как методы» (`"a,b".разделить(",")` ≡ `разделить("a,b", ",")`, см. [главу 03](03_СЛОВА_И_ОБРАЗЫ.md#вызов-в-виде-метода)). Собственное слово с тем же именем **перекрывает** встроенное.

Если не оговорено иное, при неверных типах и числе аргументов слово возвращает ошибку выполнения с подсказкой.

## Вывод и ввод

| Слово | Описание |
|-------|----------|
| `возгласи(a, b, …)` | печатает все аргументы **подряд, без разделителей**, и перевод строки. Возвращает `ничего`. Любые значения. |
| `ввод(приглашение?)` | печатает приглашение (если есть), читает строку из stdin без `\n`. На конце ввода — `ничего`. |

```
возгласи("a", 1, истина)       # a1истина
пусть имя = ввод("Имя: ")
```

Строки печатаются без кавычек, массивы — `[1, 2, 3]`, словари — `{ключ: значение}`, `ничего` — `ничего`.

## Типы и преобразования

| Слово | Описание |
|-------|----------|
| `тип(x)` | имя типа строкой: `INTEGER`, `FLOAT`, `STRING`, `BOOLEAN`, `NULL`, `ARRAY`, `HASH`, `FUNCTION`, `BUILTIN`, `INSTANCE`, `BOUND_METHOD`, `GENERATOR`, `FUTURE`, `ERROR_VALUE` |
| `строка(x)` | текстовое представление любого значения (`строка(3.0)` → `"3.0"`) |
| `число(s)` | **только из строки**: целое, если разбирается как целое, иначе дробное. Читает начало строки (`число("12abc")` → `12`); нечисловая строка — ошибка. `число(5)` — ошибка |
| `округл(x)` | округление до целого; дробное → `INTEGER`. Прибавляет 0.5 и отбрасывает дробь, поэтому для **отрицательных** чисел результат смещён (`округл(-2.6)` → `-2`); для отрицательных используйте `мат.пол`/`мат.потолок` (они возвращают `FLOAT`) |
| `длина(x)` / `размер(x)` | число символов строки (в рунах, не байтах), элементов массива или пар словаря. Для остального — ошибка |

## Числа

| Слово | Описание |
|-------|----------|
| `мин(…)`, `макс(…)` | принимают числа, массив чисел или смесь: `мин(3, 1, 2)`, `макс([4, 9, 2])`. Если все целые — результат целый |
| `абс(x)` | модуль; тип сохраняется |
| `степень(a, b)` | \(a^b\), результат всегда `FLOAT` |
| `корень(x)` | \(\sqrt{x}\), результат `FLOAT` |
| `сумма(массив)` | сумма чисел массива; целая, если все целые. Не-число в массиве — ошибка |
| `диапазон(n)` | `[0, …, n-1]` |
| `диапазон(a, b)` | `[a, …, b-1]` |
| `диапазон(a, b, шаг)` | с шагом, в том числе отрицательным: `диапазон(5, 0, -2)` → `[5, 3, 1]`. Только целые; шаг 0 — ошибка |

Остальные математические функции (`sin`, `cos`, `tan`, `лог`, `пол`, `потолок`, `пи`, `е`) — в модуле `мат`, см. [СТДЛИБ.md](СТДЛИБ.md).

## Строки

Строки неизменяемы; все слова возвращают новую строку.

| Слово | Описание |
|-------|----------|
| `разделить(s, sep)` | массив частей: `"a,b".разделить(",")` → `[a, b]`. Пустой `sep` разбивает на символы |
| `соединить(массив, sep)` | склейка: элементы любого типа приводятся к тексту |
| `заменить(s, старое, новое)` | заменяет **все** вхождения (не регулярка; для регулярок — модуль `регвыр`) |
| `верхний(s)`, `нижний(s)` | регистр (Unicode, кириллица работает) |
| `обрезать(s)` | убирает пробелы и переводы строк по краям |
| `подстрока(s, от, до)` | символы с индекса `от` до `до` (не включая); индексы в рунах; выход за границы — ошибка |
| `содержит(s, подстрока)` | `истина`/`ложь` (то же слово работает для массивов и словарей) |
| `начинается_с(s, префикс)` | `истина`/`ложь` |
| `заканчивается_на(s, суффикс)` | `истина`/`ложь` |
| `повторить(s, n)` | `"ab".повторить(3)` → `ababab`; `n < 0` — ошибка |
| `найти(s, подстрока)` | индекс первого вхождения или `-1`. **Индекс считается в байтах UTF-8**, поэтому для кириллицы он не совпадает с позицией символа (`найти("привет", "ве")` → `6`). Для позиций в символах используйте `подстрока` и цикл |

Дополнительно: конкатенация `+` (приводит остальные значения к тексту), индекс `s[i]` (символ, отрицательный — с конца), интерполяция `"{x}"`, срезы `s[1:4]`, `s[:3]`, `s[-3:]` (границы в символах; выход за границы обрезается).

## Массивы

Слова из этой группы, помеченные **✎**, **меняют массив на месте** и возвращают его же; помеченные **◇** создают новый.

| Слово | Описание |
|-------|----------|
| ✎ `добавить(а, x)` | дописывает в конец |
| ✎ `вставить(а, i, x)` | вставляет перед индексом `i` (допустимо `0 … длина`) |
| ✎ `удалить(а, i)` | удаляет элемент с индексом `i` (не по значению) |
| ✎ `сортировать(а)` | по возрастанию для чисел и строк (однотипных); со вторым аргументом — компаратор (см. ниже) |
| ✎ `реверс(а)` | разворот |
| ◇ `взять(а, n)` | первые `n` элементов (для генератора — `n` значений) |
| ◇ `пропустить(а, n)` | всё, кроме первых `n` |
| ◇ `объединить(a, b, …)` | один массив из аргументов: массивы разворачиваются на один уровень, прочие значения добавляются как есть |
| `содержит(а, x)` | глубокое сравнение; `истина`/`ложь` |
| `найти_индекс(а, ф)` | индекс первого элемента, для которого `ф(x)` истинно, или `-1` |
| `найти(а, ф)` | **сам элемент** (не индекс!) или `ничего` |

> Так как `сортировать`, `реверс`, `добавить` меняют исходный массив, для копии сначала сделайте её: `пусть копия = взять(а, длина(а))` или `объединить(а)`.

Компаратор `сортировать(а, ф)`: `ф(x, y)` возвращает истину, если `x` и `y` нужно **поменять местами**. `слово(a, b): a > b` — по возрастанию, `a < b` — по убыванию. Алгоритм квадратичный (пузырёк): для больших массивов (тысячи элементов) это медленно.

```
пусть люди = [{"имя": "Борис", "в": 30}, {"имя": "Аня", "в": 25}]
сортировать(люди, слово(a, b): a["в"] > b["в"])
```

## Функции высшего порядка

Функциональный аргумент обязан быть **словом пользователя или лямбдой** (`FUNCTION`). Встроенные слова (`длина`, `строка`) и связанные методы как колбэки не принимаются — оберните: `х => строка(х)`.

Колбэк получает **элемент и его индекс** (лишние параметры можно не объявлять).

| Слово | Описание |
|-------|----------|
| ◇ `преобразовать(а, ф)` | массив результатов `ф(x, i)` (map) |
| ◇ `фильтр(а, ф)` | элементы, для которых `ф(x, i)` истинно |
| `свернуть(а, ф, начальное?)` | `ф(накопитель, x, i)`; без начального значения берётся первый элемент (пустой массив → `ничего`) |
| `дляКаждого(а, ф)` | вызывает `ф(x, i)` ради побочных эффектов; возвращает `ничего` |
| `все(а, ф)` | `истина`, если `ф` истинна для всех (пустой массив → `истина`) |
| `любой(а, ф)` | `истина`, если хотя бы для одного |

```
возгласи([1, 2, 3, 4].фильтр(x => x % 2 == 0).преобразовать(x => x * x))   # [4, 16]
возгласи([1, 2, 3].свернуть((сум, x) => сум + x, 0))                         # 6
возгласи(["а", "б"].преобразовать((x, i) => "{i}:{x}"))                        # [0:а, 1:б]
```

## Множества (на массивах)

Работают с массивами, сравнивая элементы по текстовому представлению (`строка(x)`: значения `1` и `"1"` считаются одинаковыми). Порядок — по первому появлению; результат без повторов.

| Слово | Описание |
|-------|----------|
| `уникальные(а)` | убрать повторы |
| `объединение(а, б)` | все элементы обоих |
| `пересечение(а, б)` | общие |
| `разность(а, б)` | из `а`, которых нет в `б` |

## Словари

| Слово | Описание |
|-------|----------|
| `ключи(h)` | массив ключей в порядке добавления |
| `значения(h)` | массив значений в том же порядке |
| `получить(h, ключ, по_умолчанию?)` | значение или `по_умолчанию` (иначе `ничего`); ключ может быть любым хешируемым значением |
| `содержит(h, ключ)` | есть ли ключ |
| `длина(h)` | число пар |

Чтение/запись по ключу: `h["k"]`, `h.k`, `h["k"] = v`. Встроенного удаления ключа нет: постройте новый словарь без лишнего ключа.

```
пусть без_а = {}
для к в ключи(h)
    если к != "a": без_а[к] = h[к]
конец
```

Порядок ключей при `для`, `ключи`, `значения`, печати — порядок вставки.

## Файлы

Базовые операции без модуля (расширенные — в модуле `файлы`, см. [СТДЛИБ.md](СТДЛИБ.md)):

| Слово | Описание |
|-------|----------|
| `читать_файл(путь)` | содержимое как строка; нет файла — ошибка с подсказкой |
| `записать_файл(путь, текст)` | перезаписывает файл (права 0644); не создаёт каталоги |
| `существует_файл(путь)` | `истина`/`ложь` |

В [безопасном режиме](07_ОСОБЕННОСТИ.md) запись запрещена, а чтение и запись ограничены текущей папкой.

## Ошибки, тесты, загрузка

| Слово | Описание |
|-------|----------|
| `ошибка(значение)` | немедленно создаёт ошибку; сообщение — текстовое представление значения |
| `загрузить(путь)` | читает и выполняет файл в **текущем** окружении (см. [главу 04](04_ОШИБКИ_ТЕСТЫ_МОДУЛИ.md#загрузить)) |
| `установить(экз, "поле", значение)` | задаёт поле экземпляра по имени (только `INSTANCE`) |

`__тест__` и `__проверить__` — внутренние, их порождают `тест` и `проверить`; напрямую не вызывайте.

## Асинхронность и генераторы

| Слово | Описание |
|-------|----------|
| `все_ждать(массив)` | ждёт все `FUTURE` из массива (остальные значения оставляет как есть), возвращает массив результатов |
| `готово(f)` | `истина`, если будущее завершилось (для не-будущего — `истина`) |
| `взять(ген, n)` | первые `n` значений генератора массивом; после этого генератор закрывается |

Подробнее — [глава 03](03_СЛОВА_И_ОБРАЗЫ.md#генераторы).

## Священное Писание

Встроен полный текст **Синодального перевода** (66 книг, `data/bible/synodal.json`).

| Слово | Описание |
|-------|----------|
| `стих(книга, глава, номер)` | возвращает строку вида `Иоанн 1:1 — В начале было Слово, …` |
| `писание(книга, глава, номер)` | синоним `стих` |

Книгу можно задавать полным названием или сокращением (`"Ин"`, `"Иоанн"`, `"Быт"`, `"Бытие"`). Несуществующий стих или книга — ошибка.

```
возгласи(стих("Ин", 1, 1))
# Иоанн 1:1 — В начале было Слово, и Слово было у Бога, и Слово было Бог.
```
