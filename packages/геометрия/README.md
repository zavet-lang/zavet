# геометрия

2D-геометрия (точки, векторы, прямоугольники, площадь и принадлежность многоугольнику) и расчёт географических расстояний по формуле Хаверсина.

## Установка

```bash
zavet подключить геометрия
```

## Использование

```zavet
приими гео из "геометрия"

возгласи(гео.гео_расстояние_км(55.7558, 37.6173, 59.9343, 30.3351))
```
