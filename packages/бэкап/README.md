# бэкап

Резервное копирование наборов файлов в самодостаточный JSON-снимок с SHA-256 контрольными суммами, проверкой целостности и восстановлением.

## Установка

```bash
zavet подключить бэкап
```

## Использование

```zavet
приими бэк из "бэкап"

пусть сн = бэк.создать_снимок({"app.json": "{\"v\":1}"}, "v1")
бэк.сохранить_в_файл(сн, "backup.json")
```
