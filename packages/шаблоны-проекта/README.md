# шаблоны-проекта

Генератор структуры стартовых проектов на Завете: `cli`, `web`, `bot` и `pkg` (`пакет.json`, `главный.молитва`, `тест.молитва`, `README.md`).

## Установка

```bash
zavet подключить шаблоны-проекта
```

## Использование

```zavet
приими шаб из "шаблоны-проекта"

шаб.создать_на_диске("web", "./my-api", "my-api")
```
