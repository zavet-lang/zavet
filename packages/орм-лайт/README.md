# орм-лайт

Лёгкий построитель SQL-запросов и CRUD-репозиторий поверх `бд` (SQLite).

## Установка

```bash
zavet подключить орм-лайт
```

## Использование

```zavet
приими орм из "орм-лайт"

пусть соед = бд.открыть("app.db")
пусть users = орм.репозиторий(соед, "users")
пусть id = users.вставить({"name": "Иван", "age": 25})
пусть список = users.запрос().где("age", ">=", 18).сортировать("name", "ASC").лимит(10).все()
```
