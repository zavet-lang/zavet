# индекс-поиска

Полнотекстовый инвертированный индекс в памяти с токенизацией кириллицы/латиницы, русскими стоп-словами, TF-IDF ранжированием и сниппетами.

## Установка

```bash
zavet подключить индекс-поиска
```

## Использование

```zavet
приими поиск из "индекс-поиска"

пусть инд = поиск.создать()
инд.добавить("doc1", "Язык Завет поддерживает модули и образы")
пусть найденные = инд.искать("модули Завет")
```
