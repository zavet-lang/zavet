# тесты-моки

Шпионы и заглушки для модульных тестов на Завете: запись всех вызовов и аргументов, фиксированные и последовательные возвраты, симуляция ошибок.

## Установка

```bash
zavet подключить тесты-моки
```

## Использование

```zavet
приими моки из "тесты-моки"

пусть шпион = моки.создать()
шпион.вернуть("ок")
пусть ф = шпион.коллбэк()
ф("аргумент")
возгласи(шпион.число_вызовов()) # 1
```
