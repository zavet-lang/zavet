# единицы

Конвертер физических величин: длина, масса, температура (C/F/K), объём, скорость, время и объём данных.

## Установка

```bash
zavet подключить единицы
```

## Использование

```zavet
приими ед из "единицы"

возгласи(ед.перевести(100, "C", "F"))   # 212
возгласи(ед.размер_данных(1048576))     # 1 МБ
```
