# праздники-ru

Производственный календарь РФ: официальные праздники, определение рабочих дней, сдвиг на N рабочих дней и точный расчёт даты Православной Пасхи.

## Установка

```bash
zavet подключить праздники-ru
```

## Использование

```zavet
приими пр из "праздники-ru"

возгласи(пр.название_праздника(1, 7))     # Рождество Христово
возгласи(пр.православная_пасха(2026))     # {год: 2026, месяц: 4, день: 12}
```
