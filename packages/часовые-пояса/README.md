# часовые-пояса

Справочник часовых поясов России и мира (МСК, КЛД, ЕКБ, НСК, ВЛД, UTC, CET, EST, PST, JST и др.), перевод Unix-времени в локальные дату/время и формат ISO-8601.

## Установка

```bash
zavet подключить часовые-пояса
```

## Использование

```zavet
приими пояса из "часовые-пояса"

возгласи(пояса.в_iso(время.сейчас(), "МСК"))
```
