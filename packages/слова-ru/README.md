# слова-ru

Анализ и форматирование русского текста: подсчёт слов и предложений, время чтения, обрезка по границам слов и частотный словарь.

## Установка

```bash
zavet подключить слова-ru
```

## Использование

```zavet
приими слова из "слова-ru"

возгласи(слова.статистика("Привет, мир! Это тест."))
возгласи(слова.обрезать_по_словам("Очень длинный заголовок статьи", 18))
```
