# снимки

Снэпшот-тестирование на Завете: сохранение эталонных JSON-снимков и автоматическое обнаружение неожиданных изменений вывода.

## Установка

```bash
zavet подключить снимки
```

## Использование

```zavet
приими сн из "снимки"

пусть х = сн.создать()
х.загрузить_из_файла("snapshots.json")
проверить(х.сверить("ответ_api", {"ok": истина})["ок"])
```
