# лог

Структурированный логгер для Завета с уровнями (`отладка`, `инфо`, `внимание`, `ошибка`), текстовым и JSON-форматом, дочерними контекстами и пользовательскими приёмниками.

## Установка

```bash
zavet подключить лог
```

## Использование

```zavet
приими лог из "лог"

пусть л = лог.создать({"уровень": "инфо", "формат": "json"})
л.инфо("сервер запущен", {"порт": 8888})
```
