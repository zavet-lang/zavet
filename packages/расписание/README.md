# расписание

Разбор и проверка 5-польных cron-выражений (`*`, `*/n`, `a-b`, `a,b`) и планировщик периодических задач.

## Установка

```bash
zavet подключить расписание
```

## Использование

```zavet
приими расп из "расписание"

пусть пл = расп.планировщик()
пл.добавить("отчёт", "0 9 * * 1-5", слово() возгласи("Доброе утро!") конец)
пл.тик(0, 9, 12, 5, 2)
```
