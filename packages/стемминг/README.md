# стемминг

Русский стеммер (алгоритм Портера / Snowball) для приведения словоформ к единой основе в поисковых и аналитических задачах.

## Установка

```bash
zavet подключить стемминг
```

## Использование

```zavet
приими стем из "стемминг"

возгласи(стем.основа("книгами"))     # книг
возгласи(стем.основа("красивого"))   # красив
```
