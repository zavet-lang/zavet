# матрицы

Линейная алгебра на Завете: нулевые и единичные матрицы, сложение, умножение, транспонирование, определитель и обратная матрица (Гаусс-Жордан).

## Установка

```bash
zavet подключить матрицы
```

## Использование

```zavet
приими м из "матрицы"

пусть а = [[1, 2], [3, 4]]
возгласи(м.определитель(а))
возгласи(м.обратная(а))
```
