# морфология

Русское согласование числительных, перевод чисел и сумм в рублях прописью и работа с регистром.

## Установка

```bash
zavet подключить морфология
```

## Использование

```zavet
приими морф из "морфология"

возгласи(морф.с_числом(23, "урок", "урока", "уроков")) # 23 урока
возгласи(морф.число_прописью(1234))                     # одна тысяча двести тридцать четыре
возгласи(морф.рубли_прописью(150, 5))                   # Сто пятьдесят рублей 5 копеек
```
