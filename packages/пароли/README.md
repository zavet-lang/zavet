# пароли

Безопасное итеративное хеширование паролей со случайной солью на базе HMAC-SHA256 (так как встроенный модуль `крипто` предоставляет SHA-256 и HMAC-SHA256), сверка за постоянное время, оценка стойкости и генерация случайных паролей.

## Установка

```bash
zavet подключить пароли
```

## Использование

```zavet
приими пар из "пароли"

пусть хеш = пар.хешировать("МойПароль!2026")
проверить(пар.сверить("МойПароль!2026", хеш))
```
