# дискорд

Клиент Discord Webhook с конструктором Embed-карточек (заголовок, описание, цвет, поля, подвал) и поддержкой мок-транспорта для тестов.

## Установка

```bash
zavet подключить дискорд
```

## Использование

```zavet
приими дс из "дискорд"

пусть хук = дс.вебхук("https://discord.com/api/webhooks/...")
пусть к = дс.карточка("Статус", "Все сервисы работают").цвет(3066993)
хук.отправить("Отчёт", [к])
```
