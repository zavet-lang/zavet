# ограничитель

Ограничение частоты запросов (rate limiting) для Завета: токен-бакет (`ВедроТокенов`), скользящее окно (`СкользящееОкно`) и middleware для `веб`.

## Установка

```bash
zavet подключить ограничитель
```

## Использование

```zavet
приими ограничитель из "ограничитель"

пусть app = веб.приложение()
пусть лимит = ограничитель.ВедроТокенов(60, 60) # 60 запросов в минуту
app.использовать(ограничитель.middleware(лимит))
```
