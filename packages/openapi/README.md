# openapi

Конструктор спецификации OpenAPI 3.0.3 и встроенной HTML-документации без внешних зависимостей для модуля `веб`.

## Установка

```bash
zavet подключить openapi
```

## Использование

```zavet
приими openapi из "openapi"

пусть спека = openapi.создать("Мой сервис", "1.0.0", "Описание API")
спека.схема("Item", openapi.схема_объект({"id": openapi.схема_целое(), "name": openapi.схема_строка()}, ["id"]))
спека.маршрут("GET", "/items/:id", {
    "сводка": "Получить элемент",
    "ответы": {"200": {"описание": "OK", "схема": openapi.ссылка("Item")}},
})

пусть app = веб.приложение()
спека.подключить(app) # /openapi.json и /docs
```
