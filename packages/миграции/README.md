# миграции

Версионированные миграции схемы базы данных поверх `бд` (SQLite): применение, откат, статус и проверка контрольных сумм.

## Установка

```bash
zavet подключить миграции
```

## Использование

```zavet
приими миграции из "миграции"

пусть соед = бд.открыть("app.db")
пусть м = миграции.создать(соед)
м.добавить("001", "users", "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)", "DROP TABLE users")
м.применить()
```
