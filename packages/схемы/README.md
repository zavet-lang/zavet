# схемы

Декларативная валидация и нормализация структур данных (аналог zod/pydantic) для Завета.

## Установка

```bash
zavet подключить схемы
```

## Использование

```zavet
приими схемы из "схемы"

пусть Анкета = схемы.объект_тип({
    "имя": схемы.строка_тип().обрезать().мин(2),
    "почта": схемы.строка_тип().email(),
    "возраст": схемы.целое_тип().мин(18),
})

пусть рез = Анкета.разобрать({"имя": "Аня", "почта": "a@b.ru", "возраст": 21})
```
