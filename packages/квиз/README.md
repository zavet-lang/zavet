# квиз

Движок викторин и обучающих тестов на Завете: вопросы с вариантами ответа и весами, пошаговое прохождение, подсчёт баллов, процентов, оценки (2–5) и детальный разбор.

## Установка

```bash
zavet подключить квиз
```

## Использование

```zavet
приими квиз из "квиз"

пусть к = квиз.создать("Викторина")
к.добавить_вопрос("2 + 2 = ?", ["3", "4", "5"], 1)
к.ответить(1)
возгласи(к.итог())
```
