# финансы

Финансовые расчёты: точная работа в копейках, форматирование валют, расчёт НДС сверху/внутри, сложные проценты и аннуитетные платежи по кредитам.

## Установка

```bash
zavet подключить финансы
```

## Использование

```zavet
приими фин из "финансы"

возгласи(фин.форматировать_копейки(1234567)) # 12 345,67 ₽
возгласи(фин.аннуитет(1000000, 12, 60))
```
