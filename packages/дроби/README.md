# дроби

Точная арифметика рациональных дробей с автоматическим сокращением через НОД, без погрешностей плавающей точки.

## Установка

```bash
zavet подключить дроби
```

## Использование

```zavet
приими др из "дроби"

пусть а = др.создать(1, 3)
пусть б = др.из_строки("1/6")
возгласи(а.плюс(б).в_строку()) # 1/2
```
