# вебхуки

Подпись исходящих и проверка входящих вебхуков по схеме HMAC-SHA256 с защитой от replay-атак, отправка с повторами и middleware для `веб`.

## Установка

```bash
zavet подключить вебхуки
```

## Использование

```zavet
приими вебхуки из "вебхуки"

# Входящий вебхук
пусть app = веб.приложение()
app.использовать(вебхуки.middleware("ваш-секрет"))
app.пост("/webhook", слово(запрос): веб.json({"ок": истина}))

# Исходящий вебхук
вебхуки.отправить("https://partner.ru/hook", "оплата.успех", {"id": 42}, "ваш-секрет")
```
