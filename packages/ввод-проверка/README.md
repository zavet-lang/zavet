# ввод-проверка

Санитизация пользовательского ввода на Завете: очистка HTML/XSS, валидация безопасных URL, защита от path traversal и генерация безопасных имён файлов.

## Установка

```bash
zavet подключить ввод-проверка
```

## Использование

```zavet
приими ввод из "ввод-проверка"

проверить(ввод.безопасный_url("https://example.com"))
проверить(не ввод.безопасный_путь("../secret.txt"))
```
