# markdown

Парсер и рендерер Markdown в безопасный HTML с защитой от XSS: заголовки, абзацы, списки, цитаты, блоки кода, жирный, курсив и ссылки.

## Установка

```bash
zavet подключить markdown
```

## Использование

```zavet
приими md из "markdown"

пусть html = md.в_html("# Привет\n\nТекст с **выделением** и `кодом`.")
```
