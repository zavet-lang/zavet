# cors-правила

Гибкий CORS middleware для стандартного модуля `веб`.

## Установка

```bash
zavet подключить cors-правила
```

## Использование

```zavet
приими cors из "cors-правила"

пусть app = веб.приложение()
app.использовать(cors.middleware({
    "источники": ["https://zavet.ru", "https://*.zavet.ru"],
    "методы": ["GET", "POST", "PUT", "DELETE"],
    "учётные_данные": истина,
    "открытые_заголовки": ["X-Request-Id"],
    "макс_возраст": 3600,
}))
```
