# прогресс

Полоса прогресса с процентами и счётчиком шагов, а также кадры спиннера для CLI-утилит на Завете.

## Установка

```bash
zavet подключить прогресс
```

## Использование

```zavet
приими прог из "прогресс"

пусть п = прог.полоса(100, 25, "Загрузка")
п.шаг(40)
возгласи(п.строка_полосы())
```
