# гитхаб

Клиент GitHub REST API v3 на Завете: получение информации о репозиториях, релизах, списке задач (issues), создание задач и комментариев.

## Установка

```bash
zavet подключить гитхаб
```

## Использование

```zavet
приими gh из "гитхаб"

пусть кл = gh.клиент(ос.переменная("GITHUB_TOKEN", ""))
возгласи(кл.репозиторий("zavet-lang", "zavet"))
```
