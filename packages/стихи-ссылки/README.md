# стихи-ссылки

Разбор и форматирование ссылок на стихи Писания (`Ин 3:16`, `Быт. 1:1-5`, `1 Кор 13:4-7`, `Пс 22`) с нормализацией сокращений книг.

## Установка

```bash
zavet подключить стихи-ссылки
```

## Использование

```zavet
приими ссылки из "стихи-ссылки"

пусть р = ссылки.разобрать("1 Кор. 13:4-7")
возгласи(ссылки.форматировать(р)) # 1-е Коринфянам 13:4-7
```
