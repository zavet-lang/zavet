# секреты

Локальное зашифрованное хранилище секретов (ключ-значение) с потоковым шифрованием на базе HMAC-SHA256, случайным nonce и проверкой целостности MAC-тегом.

## Установка

```bash
zavet подключить секреты
```

## Использование

```zavet
приими сек из "секреты"

пусть с = сек.сейф("мастер-ключ")
с.положить("DB_PASS", "суперсекрет")
возгласи(с.взять("DB_PASS"))
```
