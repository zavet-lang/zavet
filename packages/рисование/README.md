# рисование

Генератор векторной графики SVG на Завете: холст, прямоугольники со скруглением, круги, линии и безопасно экранированный текст.

## Установка

```bash
zavet подключить рисование
```

## Использование

```zavet
приими рис из "рисование"

пусть х = рис.холст(300, 150, "#f8fafc")
х.круг(150, 75, 40, "#2563eb").текст(150, 80, "Завет", 18, "#fff", "middle")
файлы.записать("logo.svg", х.в_svg())
```
