# конфиг

Слоистая загрузка конфигурации: разбор `.env`, JSON-файлов, переопределений, типизированные геттеры и проверка обязательных параметров.

## Установка

```bash
zavet подключить конфиг
```

## Использование

```zavet
приими конф из "конфиг"

пусть к = конф.создать({"PORT": 3000})
к.из_env_файла(".env")
возгласи(к.число_п("PORT"))
```
