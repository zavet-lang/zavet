# шахматы

Шахматная доска 8×8 на Завете: загрузка и экспорт FEN, валидация ходов всех фигур (пешка, конь, слон, ладья, ферзь, король), история ходов и ASCII-отрисовка.

## Установка

```bash
zavet подключить шахматы
```

## Использование

```zavet
приими шах из "шахматы"

пусть д = шах.новая_партия()
д.сходить("e2", "e4")
д.сходить("e7", "e5")
возгласи(д.нарисовать())
```
