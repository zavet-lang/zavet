# графики-ascii

Текстовая визуализация данных в терминале: однострочные спарклайны (`искры`) и горизонтальные столбчатые диаграммы (`столбцы`).

## Установка

```bash
zavet подключить графики-ascii
```

## Использование

```zavet
приими гр из "графики-ascii"

возгласи(гр.искры([1, 3, 2, 5, 8, 4]))
возгласи(гр.столбцы([{"метка": "A", "значение": 10}, {"метка": "B", "значение": 25}]))
```
