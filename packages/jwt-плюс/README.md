# jwt-плюс

Работа с JWT HS256: выпуск пар `access` + `refresh`, проверка подписи и срока жизни, проверка ролей, ротация `refresh`-токенов и чёрный список отозванных `jti`.

## Установка

```bash
zavet подключить jwt-плюс
```

## Использование

```zavet
приими jwt из "jwt-плюс"

пусть м = jwt.менеджер("sec-a", "sec-r")
пусть пара = м.выпустить_пару("u1", ["admin"])
возгласи(м.проверка_доступа(пара["access"], "admin"))
```
