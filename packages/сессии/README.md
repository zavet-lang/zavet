# сессии

Cookie-сессии для веб-приложений Завета с HMAC-подписью, хранением в памяти или SQLite, скользящим продлением TTL и flash-сообщениями.

## Установка

```bash
zavet подключить сессии
```

## Использование

```zavet
приими сессии из "сессии"

пусть app = веб.приложение()
пусть менеджер = сессии.создать({
    "секрет": "ваш-секретный-ключ",
    "хранилище": сессии.ХранилищеБд("sessions.db"),
    "ttl": 86400,
})
app.использовать(менеджер.middleware())

app.пост("/login", слово(запрос)
    запрос["сессия"]["user_id"] = 7
    аминь веб.json({"ок": истина})
конец)
```
