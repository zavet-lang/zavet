# telegram-меню

Конструктор inline-клавиатур, сеток кнопок, пагинации списков и машина состояний диалогов (FSM) для Telegram-ботов на Завете.

## Установка

```bash
zavet подключить telegram-меню
```

## Использование

```zavet
приими меню из "telegram-меню"

пусть кл = меню.сетка([меню.кнопка("Да", "yes"), меню.кнопка("Нет", "no")], 2)
```
