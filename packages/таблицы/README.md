# таблицы

Табличные данные в памяти: фильтрация, сортировка, группировка, агрегации, inner join, импорт/экспорт CSV и вывод текстовой таблицы.

## Установка

```bash
zavet подключить таблицы
```

## Использование

```zavet
приими таблицы из "таблицы"

пусть т = таблицы.создать([
    {"отдел": "А", "сумма": 100},
    {"отдел": "А", "сумма": 250},
    {"отдел": "Б", "сумма": 80},
])
пусть отчёт = т.группировать("отдел", {"итого": ["сумма", "сумма"], "шт": ["колво", "*"]})
возгласи(отчёт.форматировать())
```
