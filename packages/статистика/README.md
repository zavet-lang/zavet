# статистика

Описательная статистика: среднее, медиана, мода, дисперсия, стандартное отклонение, перцентили, корреляция Пирсона и линейная регрессия.

## Установка

```bash
zavet подключить статистика
```

## Использование

```zavet
приими стат из "статистика"

возгласи(стат.сводка([2, 4, 4, 5, 7, 9]))
возгласи(стат.регрессия([1, 2, 3], [2, 4, 6]))
```
