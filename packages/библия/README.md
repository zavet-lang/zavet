# библия

Чтение, выборка стихов/диапазонов, полнотекстовый поиск и «стих дня» по корпусу Синодальной Библии в формате JSON.

## Установка

```bash
zavet подключить библия
```

## Использование

```zavet
приими биб из "библия"

пусть б = биб.из_файла("synodal.json")
возгласи(б.стих("Бытие", 1, 1))
возгласи(б.искать("любовь", 5))
```
