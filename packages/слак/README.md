# слак

Клиент Slack Incoming Webhook и конструктор блоков Block Kit (`заголовок`, `секция`, `разделитель`, `контекст`).

## Установка

```bash
zavet подключить слак
```

## Использование

```zavet
приими слак из "слак"

пусть хук = слак.вебхук("https://hooks.slack.com/services/...")
хук.отправить("Сборка готова", [слак.заголовок("CI"), слак.секция("Все тесты пройдены")])
```
