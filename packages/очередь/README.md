# очередь

Постоянная очередь фоновых задач поверх SQLite (`бд`): приоритеты, отложенный запуск, автоматические повторы и обработчик `обработать_все`.

## Установка

```bash
zavet подключить очередь
```

## Использование

```zavet
приими очередь из "очередь"

пусть оч = очередь.создать("jobs.db")
оч.поставить("email", {"to": "user@example.com"}, {"приоритет": 5})
оч.обработать_все({
    "email": слово(данные, задача): возгласи("Отправка:", данные["to"]),
})
```
