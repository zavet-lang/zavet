# урок-тренажёр

Тренажёр интервального повторения по алгоритму SM-2 (как в Anki): колоды карточек, оценка запоминания 0–5, адаптивный расчёт интервалов и выборка карточек к повторению.

## Установка

```bash
zavet подключить урок-тренажёр
```

## Использование

```zavet
приими трен из "урок-тренажёр"

пусть к = трен.колода("Словарь")
к.добавить("1", "return", "аминь")
к.оценить("1", 5, 0)
```
