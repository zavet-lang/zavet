# транслит

Транслитерация кириллицы в латиницу (ГОСТ и ICAO), обратная транслитерация и генератор чистых URL-slug.

## Установка

```bash
zavet подключить транслит
```

## Использование

```zavet
приими транслит из "транслит"

возгласи(транслит.в_латиницу("Добрый день"))        # Dobryj den
возгласи(транслит.slug("Урок №1: Первые шаги!"))    # urok-1-pervye-shagi
```
