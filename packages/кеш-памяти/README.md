# кеш-памяти

LRU- и TTL-кеш в памяти с ограничением числа записей, ленивой фабрикой `получить_или` и статистикой попаданий.

## Установка

```bash
zavet подключить кеш-памяти
```

## Использование

```zavet
приими кеш из "кеш-памяти"

пусть к = кеш.создать({"макс_размер": 1000, "ttl": 300})
пусть профиль = к.получить_или("user:1", слово(): загрузить_из_бд(1))
```
