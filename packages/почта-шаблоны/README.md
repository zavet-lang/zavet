# почта-шаблоны

Генератор адаптивных HTML- и текстовых писем для транзакционных рассылок: приветствие, подтверждение почты (код или ссылка), сброс пароля и произвольные шаблоны с XSS-экранированием.

## Установка

```bash
zavet подключить почта-шаблоны
```

## Использование

```zavet
приими почта из "почта-шаблоны"

пусть письмо = почта.приветствие("Иван", "МойПроект", "https://example.com")
возгласи(письмо["тема"])
```
