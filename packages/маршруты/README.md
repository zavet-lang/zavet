# маршруты

Расширенная маршрутизация поверх стандартного модуля `веб`: типизированные параметры пути, версионирование API, REST-ресурсы (CRUD) и обратная генерация URL.

## Установка

```bash
zavet подключить маршруты
```

## Использование

```zavet
приими маршруты из "маршруты"

пусть app = веб.приложение()
пусть api = маршруты.создать(app, "/api").версия(1)

api.получить("/users/{id:int}", слово(запрос)
    аминь веб.json({"id": запрос["типы"]["id"]})
конец, {"имя": "user.get"})

возгласи(api.url_для("user.get", {"id": 42}, {"full": 1}))
# /api/v1/users/42?full=1
```

## Встроенные типы параметров

`int`, `uint`, `float`, `uuid`, `slug`, `str`. Свои типы добавляются через `добавить_тип(название, проверщик)`.
