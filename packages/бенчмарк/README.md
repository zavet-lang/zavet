# бенчмарк

Микробенчмарки производительности кода на Завете: замер времени выполнения, среднего времени и операций в секунду, а также сравнительные отчёты.

## Установка

```bash
zavet подключить бенчмарк
```

## Использование

```zavet
приими бенч из "бенчмарк"

пусть р = бенч.замерить("цикл", 1000, слово(i) пусть s = i * i конец)
возгласи(р)
```
