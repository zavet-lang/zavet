# кеш-http

HTTP-кеширование для модуля `веб`: автоматический расчёт ETag, обработка `If-None-Match` с возвратом `304 Not Modified`, конструктор `Cache-Control` и проверка `If-Modified-Since`.

## Установка

```bash
zavet подключить кеш-http
```

## Использование

```zavet
приими кеш из "кеш-http"

пусть app = веб.приложение()
app.использовать(кеш.middleware({
    "cache_control": {"публичный": истина, "макс_возраст": 300},
}))
```
