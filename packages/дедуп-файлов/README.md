# дедуп-файлов

Поиск дубликатов файлов по SHA-256 хешу содержимого, подсчёт лишних байт и безопасный план очистки.

## Установка

```bash
zavet подключить дедуп-файлов
```

## Использование

```zavet
приими дедуп из "дедуп-файлов"

пусть отчёт = дедуп.сканировать("./documents")
возгласи("Лишних файлов:", отчёт["лишних_файлов"])
возгласи("К удалению:", дедуп.план_очистки(отчёт))
```
