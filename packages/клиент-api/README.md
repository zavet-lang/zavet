# клиент-api

HTTP API-клиент поверх стандартного модуля `http`: базовый URL, Bearer/API-ключ, автоматические повторы с экспоненциальной паузой, перехватчики и разбор JSON.

## Установка

```bash
zavet подключить клиент-api
```

## Использование

```zavet
приими клиент из "клиент-api"

пусть api = клиент.создать({
    "база": "https://api.example.com/v1",
    "повторы": 3,
    "пауза_мс": 250,
}).с_токеном("ваш-токен")

пусть ответ = api.получить("/users", {"limit": 10})
если ответ["ок"]
    возгласи(ответ["json"])
конец
```
