## Установка одной командой

**Linux / macOS:**
```bash
curl -fsSL https://raw.githubusercontent.com/zavet-lang/zavet/main/install.sh | sh
```

Скрипт скачает архив с GitHub Releases, проверит SHA256 (`checksums.txt`) и установит `zavet` в `~/.zavet/bin` без `sudo`. [Посмотреть исходник](install.sh).

**Homebrew (macOS / Linux):**
```bash
brew install zavet-lang/tap/zavet
```

**Scoop (Windows):**
```powershell
scoop bucket add zavet https://github.com/zavet-lang/scoop-bucket
scoop install zavet
```

**Другие способы** (APT `.deb`, сборка из исходников) — в разделе [Установка](#установка).

## Зачем нужен Завет

**Завет** — выразительный язык программирования на библейском русском, собранный в один самодостаточный бинарник `zavet`:

- **Читается как русская речь:** `пусть`, `измени`, `слово`, `аминь`, `образ`, `род`, `если`, `для`, `доколе`, `разбери`, `попытка`, `приими`, `открой`.
- **Ошибки как наставления:** интерпретатор не сыплет сухими кодами, а объясняет, что пошло не так и как исправиться, с файлом, строкой и стеком вызовов.
- **Всё из коробки:** веб-фреймворк, SQLite и PostgreSQL, WebSocket, SMTP-почта, YAML, JSON, ZIP/gzip/zlib, криптография, шаблонизатор, 2D-окно с иконками Font Awesome, интеграция с Python и Node.js.
- **Полный набор инструментов:** байткод-VM (`--vm`), песочница (`--безопасный`), пошаговый отладчик, форматтер, линтер, автогенератор документации API, LSP и MCP-сервер.
- **Синодальный перевод Библии:** встроенные `стих(...)` и `писание(...)`.

## Установка

**Одной командой (Linux / macOS):**
```bash
curl -fsSL https://raw.githubusercontent.com/zavet-lang/zavet/main/install.sh | sh
```
Скачивает архив с GitHub Releases, проверяет `checksums.txt` (SHA256) и ставит в `~/.zavet/bin` без `sudo`.

**Homebrew (macOS / Linux):**
```bash
brew install zavet-lang/tap/zavet
```
Каск публикуется в [zavet-lang/homebrew-tap](https://github.com/zavet-lang/homebrew-tap). Черновик формулы: [`packaging/homebrew/zavet.rb`](packaging/homebrew/zavet.rb).

**Scoop (Windows):**
```powershell
scoop bucket add zavet https://github.com/zavet-lang/scoop-bucket
scoop install zavet
```
Манифест публикуется в [zavet-lang/scoop-bucket](https://github.com/zavet-lang/scoop-bucket). Черновик: [`packaging/scoop/zavet.json`](packaging/scoop/zavet.json).

**APT (Debian / Ubuntu):**
Скачайте `.deb` из GitHub Releases и выполните:
```bash
sudo apt install ./zavet_1.1.0_amd64.deb
```
Скрипт локальной сборки `.deb`: [`packaging/apt/build-deb.sh`](packaging/apt/build-deb.sh).

**Сборка из исходников (нужен Go 1.26+):**
```bash
go build -ldflags "-X main.Version=1.1.0" -o zavet .
```
На Windows:
```powershell
go build -ldflags "-X main.Version=1.1.0" -o zavet.exe .
```

## Запуск и режимы

```
zavet файл.молитва                          # выполнить файл
zavet запустить                             # выполнить точку входа из пакет.json
zavet --безопасный файл.молитва             # песочница (cwd, без записи/процессов/серверов)
zavet --безопасный --разрешить-хост=api.ru файл.молитва
zavet --vm файл.молитва                     # байткод-VM (функции, циклы, массивы)
zavet                                       # интерактивный режим (REPL)
```

## Пакеты и реестр

Завет использует git/GitHub как источник пакетов и содержит встроенный каталог проверенных пакетов (`валидатор`, `дата`, `тг`, `цвета` в `registry/registry.json`), который работает даже без сети и объединяется с онлайн-реестром.

```
zavet инит мой_проект                       # создать пакет.json и главный.молитва
zavet реестр                                # показать все пакеты каталога
zavet реестр тг                             # поиск по имени, категории или описанию
zavet подключить тг                         # установить по короткому имени
zavet подключить github.com/у/п@v1.0.0      # полный URL и тег
zavet подключить                            # установить всё из пакет.json + пакет.lock
zavet список                                # установленные пакеты
zavet удалить тг                            # удалить пакет
```

Подробнее — в [главе 04](docs/04_ОШИБКИ_ТЕСТЫ_МОДУЛИ.md#пакеты).

## Инструменты

### Форматирование кода (`формат`)

Приводит код к единому канону из [СТИЛЬ.md](СТИЛЬ.md):

```
zavet формат файл.молитва        # вывести в stdout
zavet формат -в файл.молитва     # переписать файл на месте
zavet формат -в .                # все .молитва в проекте рекурсивно
```

### Проверка кода (`проверить`)

Линтер находит потенциальные проблемы без запуска программы (неиспользуемые переменные/слова, затенение, недостижимый код, пустые блоки, попытка изменить `пусть`):

```
zavet проверить файл.молитва
zavet проверить .
```

### Генератор документации API (`док`)

Извлекает `#`-комментарии перед объявлениями, сигнатуры слов (включая параметры по умолчанию и опциональные типы), образы с методами и роды в чистый Markdown:

```
zavet док файл.молитва                      # Markdown в stdout
zavet док src/ -o API.md                    # вся папка в файл
zavet док src/ --только-экспорт -o API.md   # только объявления с открой
```

### Интерактивный отладчик (`отладка`)

Пошаговое выполнение с точками останова (`точка N`), просмотром переменных (`переменные`), вычислением выражений (`вычислить x + 1`), стеком вызовов (`стек`) и просмотром исходника (`код`):

```
zavet отладка программа.молитва
```

### LSP-сервер (`lsp`)

`zavet lsp` запускает Language Server Protocol по stdio (автодополнение, hover, переход к определению, поиск ссылок, переименование, диагностика в реальном времени, сигнатуры параметров). В репозитории есть расширение для VS Code — [`vscode-extension/`](vscode-extension/).

### MCP-сервер (`mcp`)

`zavet mcp` запускает Model Context Protocol сервер для ИИ-ассистентов (выполнение кода, форматирование, линтер, справка по модулям, поиск пакетов):

```json
{
  "mcpServers": {
    "zavet": { "command": "zavet", "args": ["mcp"] }
  }
}
```

Подробнее обо всех инструментах — в [главе 06](docs/06_ИНСТРУМЕНТЫ.md).

## Основы языка

### Переменные и опциональные типы

```
пусть имя = "Иван"                 # неизменяемая связь
измени счётчик = 0                 # изменяемая переменная
счётчик += 5

# Опциональные аннотации типов (проверяются во время выполнения):
пусть возраст: целое = 30
измени отчество: строка? = ничего  # «?» допускает ничего
```

### Типы данных

```
пусть целое_число = 42
пусть дробь = 3.14
пусть текст = "строка"
пусть флаг = истина                # или ложь
пусть список = [1, 2, 3]
пусть словарь = {"ключ": "значение"}
пусть пусто = ничего
```

### Интерполяция строк

В двойных кавычках выражения в `{...}` вычисляются; одинарные кавычки — без интерполяции:

```
пусть имя = "Аня"
возгласи("Мир тебе, {имя}!")
возгласи("2 + 2 = {2 + 2}")
```

### Условия

```
если возраст >= 18
    возгласи("Взрослый")
иначе если возраст >= 14
    возгласи("Подросток")
иначе
    возгласи("Ребёнок")
конец

# Короткая форма и выражение:
пусть статус = если возраст >= 18: "взрослый" иначе: "юный"
```

### Циклы

```
для i от 1 до 10
    возгласи(i)
конец

для i от 0 до 100 по 5             # с шагом 5
    возгласи(i)
конец

для имя в ["Аня", "Боря", "Вася"]
    возгласи(имя)
конец

измени k = 0
доколе k < 5
    k += 1
    если k == 3: продолжи
    если k == 5: прерви
    возгласи(k)
конец
```

### Слова (функции)

```
слово приветствовать(имя: строка = "Друг") -> строка
    аминь "Мир тебе, {имя}!"
конец

возгласи(приветствовать("Маша"))

# Короткая форма с автоматическим возвратом:
слово квадрат(x: число) -> число: x * x

# Лямбда:
пусть удвоить = x => x * 2
```

### Образы (классы) и наследование

```
образ Животное
    слово создать(имя: строка)
        это.имя = имя
    конец

    слово говорить() -> строка
        аминь "{это.имя} издаёт звук"
    конец
конец

образ Кот наследует Животное
    слово говорить() -> строка
        аминь "{это.имя} мяукает"
    конец
конец

пусть барсик = Кот("Барсик")
возгласи(барсик.говорить())
```

### Выбор: `разбери`

```
пусть день_недели = разбери день
    когда 1: "Понедельник"
    когда 2: "Вторник"
    когда 3: "Среда"
    иначе: "Иной день"
конец
```

### Обработка ошибок

```
попытка
    пусть х = 10 / 0
поймать e
    возгласи("Перехвачено: ", e)
всегда
    возгласи("Завершено")
конец
```

При необработанной ошибке Завет выводит понятное наставление:

```
❌ ОШИБКА [файл.молитва:1] сын мой, не сотвори деления на ноль
📖 Наставление: Вникни, что делитель не нуль, прежде чем делить.
```

### Встроенные тесты

```
тест "сложение работает"
    проверить 2 + 3 == 5
    проверить -1 + 1 == 0
конец
```

## Стандартная библиотека

### Два стиля вызова

Любое встроенное слово `f(объект, ...)` работает и как метод `объект.f(...)`:

```
длина([1, 2, 3])        ↔  [1, 2, 3].длина()
добавить(arr, 5)        ↔  arr.добавить(5)
заменить(s, "a", "b")   ↔  s.заменить("a", "b")
ключи(h)                ↔  h.ключи()
```

### Встроенные модули (доступны без импорта)

| Модуль | Назначение |
|--------|------------|
| `мат` | `пи`, `е`, `sin`, `cos`, `tan`, `лог`, `лог10`, `пол`, `потолок`, `корень`, `степень` |
| `время` | `сейчас`, `метка`, `строка`, `год`/`месяц`/`день`/`час`/`минута`/`секунда`, `спать`, `разобрать` |
| `json` | `разобрать`, `создать` |
| `yaml` | `разобрать`, `создать` (чистый Go, без внешних зависимостей) |
| `регвыр` | `найти`, `заменить`, `совпадает` |
| `http` | клиент (`получить`/`пост`/`положить`/`удалить`/`патч`) и сервер (`сервер`, `приложение`) |
| `веб` | веб-фреймворк: маршруты `:id`/`*path`, `группа`, `использовать`, `веб.cors`, `веб.логгер`, `веб.json`/`html`/`текст`/`редирект`/`ошибка`/`кука`, `при_ошибке`, `обработать` (тесты без сети) |
| `почта` | SMTP (`отправить` с STARTTLS/TLS), сборка MIME (`собрать`), `проверить_адрес` |
| `крипто` | `sha256`/`sha1`/`md5`, `hmac_sha256`/`hmac_sha1`, AES-CBC, JWT HS256, `base64`/`hex` |
| `сжатие` | `gzip_сжать`/`распаковать`, `zlib_сжать`/`распаковать`, `zip_создать`/`список`/`распаковать` |
| `бд` | SQLite (`открыть`) и PostgreSQL (`подключить`): `выполнить`, `запрос`, `строка`, `значение`, `транзакция`, `подготовить`, `вставить_много`, `мигрировать`, `таблицы`, `колонки` |
| `вс` | WebSocket-клиент (`подключить`) и сервер (`сервер`) |
| `шаблон` | шаблонизатор HTML/текста (`рендер`, `файл`, `экранировать`) |
| `csv` | `разобрать`, `с_заголовками`, `строка` |
| `случайное` | `число`, `целое`, `элемент` |
| `файлы` | `читать`, `записать`, `добавить`, `существует`, `удалить`, `переименовать`, `список`, `создать_дир`, `удалить_дир`, `размер`, `это_файл`, `это_дир` |
| `путь` | `соединить`, `имя`, `расширение`, `директория`, `абсолютный`, `относительный`, `очистить` |
| `ос` | `переменная`, `установить_переменную`, `аргументы`, `выход`, `текущая_директория`, `сменить_директорию`, `домашняя_директория`, `временная_директория` |
| `cli` | парсинг аргументов командной строки |
| `питон` / `js` | вызов Python 3 и Node.js (`доступен`, `выражение`, `выполнить`, `файл`) с JSON-мостом |
| `окно` | 2D-графика, текст, иконки Font Awesome 6 Solid, мышь и клавиатура ([ОКНО.md](docs/ОКНО.md)) |

Полный справочник — [docs/СТДЛИБ.md](docs/СТДЛИБ.md) и [docs/05_ВСТРОЕННЫЕ.md](docs/05_ВСТРОЕННЫЕ.md).

## Сравнение с Python и JavaScript

| Завет | Python | JavaScript |
|-------|--------|------------|
| `пусть x = 5` | `x = 5` | `const x = 5` |
| `измени x = 5` | `x = 5` | `let x = 5` |
| `слово f(x: целое) -> целое` | `def f(x: int) -> int:` | `function f(x) {}` |
| `аминь x` | `return x` | `return x;` |
| `если ... иначе` | `if ... else` | `if ... else` |
| `доколе` | `while` | `while` |
| `для x в y` | `for x in y` | `for (const x of y)` |
| `образ` | `class` | `class` |
| `создать` | `__init__` | `constructor` |
| `это` | `self` | `this` |
| `истина` / `ложь` | `True` / `False` | `true` / `false` |
| `ничего` | `None` | `null` |
| `выдать` | `yield` | `yield` |
| `асинх` / `ждать` | `async` / `await` | `async` / `await` |
| `возгласи(x)` | `print(x)` | `console.log(x)` |
| `конец` | (отступы) | `}` |
